# 长立 Odoo 外贸订单 CRM

## 目标

覆盖客户询价、报价审批、议价、销售订单会签、合同、发货、提单、发票与收款跟踪，并形成可培训、可验收的操作手册。

## 已确认的关键设计

- 报价使用独立快照层，允许无长立编号先报价，避免污染产品主数据。
- 销售订单必须来源于报价；支持整单、部分明细、复购清单及跨报价组合生成。
- 报价审批后生成“报价跟踪”活动，截止为审批日 + 3 天。
- 订单审批链：跟单 → 计划 → 采购 → 生产 → 仓库 → 侯总终审。
- 发货完成后自动生成发票；提单发放使用独立审批流。

## 近期新增范围

- 从 Odoo Online 迁移至本地部署并迁移数据，实现自主可控。
- 销售、采购、仓库、财务、质量、生产培训。
- 仓库整理与数据迁移；采购订单及库存单位换算错误修复。
- 质检与 CRM 优化；负库存限制、数据库自动备份。
- 德国网站样式迁移到 Odoo，支持英/德/中三语；需评估重构差异与同服务器负载。

## 待确认/风险

- 网站无法承诺 100% 像素级还原；Odoo 主题、颜色与字体体系不同。
- 网站与后台共用服务器会增加应用与数据库负载，需要容量与备份方案。
- 发货审批人、提单审批人、活动分配人与期限仍需以客户确认结果为准。
