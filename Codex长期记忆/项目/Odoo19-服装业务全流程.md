# Odoo 19 服装业务全流程

## 方案主线

- 按 Odoo 19 Enterprise 设计：款式开发 → 供应商询价与打样 → 样品/版型确认 → 客户报价审批 → 客户确认 → 正式采购 → 供应商预付款 → 大货备货 → 出货前质检 → 货代集货/包装 → 收货或客户交付 → 供应商及客户结算。
- 款式与版本使用 PLM/ECO；颜色、尺码用产品属性和变体；供应商多轮报价使用 RFQ/替代询价；样衣 PO 与大货 PO 分开。
- 客户确认销售订单后，可用 MTO + Buy 触发正式采购；销售与采购审批用 Studio 审批规则，但供应商出货前 QC、结构化装箱单及货代协同需要结合业务做扩展。
- 方案持续区分“原生能力 / Studio 配置 / 二次开发”，尚未确认客户实际模块许可、DPO 含义、货权时点和直送/入仓路径。
