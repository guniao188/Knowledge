# 15.0版本条码模块stock_barcode在社区版应用的修改

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/15-0stock-barcode-832>

1.  企业版文件夹 web_enterprise\static\src\webclient\barcode 拷贝到 web\static\src\webclient\barcode

2.  拷贝过来的文件夹中的文件 web\static\src\webclient\barcode\barcode_scanner.js 代码行 ‘jsLibs: ["/web_enterprise/static/lib/zxing-library/zxing-library.js"],’  改成 ‘jsLibs: ["/web/static/lib/zxing-library/zxing-library.js"],’  该代码行增加了电脑或手机摄像头扫码功能（扫二维码较容易识别）

3.  模块 web_mobile 一并挪移到社区版，文件 web_mobile\\_manifest__.py 中，依赖模块(depends)从web_enterprise改成 web

4.  文件 stock_barcode\static\src\components\stock_barcode_menu.js 代码行 '@web_enterprise/webclient/barcode/barcode_scanner' 改成‘@web/webclient/barcode/barcode_scanner’

5.  文件 stock_barcode\static\src\components\main.js 代码行 '@web_enterprise/webclient/barcode/barcode_scanner' 改成‘@web/webclient/barcode/barcode_scanner’

6.  重启Odoo，刷新页面即可生效

7.  有时候会出现，进入条码模块后，点击左上角的箭头(  改成  。即 # 换成 /web
