# Odoo17支持WebApp安装

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:肖相扶 | 2023-11-22
> <http://www.thinkltd.cn/forum/1/odoo17webapp-3807>

Odoo17支持渐进式Web应用(PWA，Progressive Web App，参考：[https://blog.csdn.net/weixin_44786530/article/details/130364084](https://blog.csdn.net/weixin_44786530/article/details/130364084)) 。PWA技术可以在Google、微软Edge等浏览器中，将当前浏览的页面一键变成本地化安装的App。具体设置方法如下：

1.  技术设置中，找到 Progressive Web App，设置本地化安装的App的名称。

![[1-odoo17webapp-3807-e0e03d9c.png]]

2.  Odoo访问的浏览器地址栏，点击应用安装的按钮，将Odoo变成一个自定义名字的本地化APP。如下截图是微软Edge浏览器示例。目前支持PWA技术的浏览器有微软Edge、Google Chrome，火狐浏览器似乎不支持。

![[1-odoo17webapp-3807-d7b92fed.png]]

3.  而后，在桌面或开始菜单中，有一个新应用“开源智造”。

![[1-odoo17webapp-3807-a8fcf86e.png]]

4.  点击应用，直接打开App，进入Odoo应用界面，而不是浏览器界面

![[1-odoo17webapp-3807-4aa333b4.png]]
