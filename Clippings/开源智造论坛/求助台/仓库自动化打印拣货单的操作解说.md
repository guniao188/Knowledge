## 补充/答案 1

自动打印是一个单独的py程序【auto_print.py】。

通过在windows上设置定时任务 使用odoo rpc 链接到目标数据库查询符合打印条件的单据然后打印。

**准备工作**

windows 电脑、打印机

python3 版本推荐3.7

odoo

准备一台windows电脑并链接打印机，并将其设置为默认的打印机,测试打印机是否正常打印。

安装python3  记得把python3添加到环境变量【参考\https://www.runoob.com/python3/python3-install.html 】
安装好python3后，再安装打印所依赖的python包 ---- win32api 和 win32print

pip install pypiwin32 -i https://pypi.tuna.tsinghua.edu.cn/simple/

pip3 install copy2 -i https://pypi.tuna.tsinghua.edu.cn/simple/

**注意事项：**

1 . 当计划任务时间间隔设置很短时（如1分钟）可能会出现重复打印单据的情况。

- 原因是当前打印任务没有结束（执行超过一分钟），下个计划任务又开始执行，因为前面的任务没有结束，下一个任务又开始使得系统订单状态来不及跟新，再次执行的计划任务还认为是没有打印故下载打印。

- 如何避免:

-   1. 计划任务间隔延长

## 补充/答案 2

程序再优化，可以增加【打印日期时间戳】，方便查到当天打印了多少单据。

尤其是在遇到本地打印机出问题或是卡纸了，队列里又只能看到尚未打过的，前面的不确定卡坏了几个没正常打印出来。

