# Odoo14会计凭证编号规则

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/odoo14-709>

1.  Odoo以前的版本中，会计凭证的编号规则取自“日记账（Journal）”上的凭证编码Sequence。Odoo 14.0中，Journal上没有了Sequence的设置。

2.  Odoo14.0中凭证编码规则是，Journal上的 Code + “四位年份/两位月份/四位序号”，红冲凭证的编码规则是，在正常编码规则的前面加上“R”（字段refund_sequence勾选的话）。该编码规则参见代码  ODOO14\source\addons\account\models\account_move.py   方法 def _get_starting_sequence(self):

3.  凭证号编码时候，系统查找同一个日记账(Journal)上的会计凭证，取最后（最近）的会计凭证，取其凭证号，如果和本凭证是同一个月份，则本凭证的凭证号在查找到的凭证号上加1。如果不是同一个月份，则取0001作为凭证号（前缀、年份保持一致）。如果没查找到凭证（该日记账的第一个凭证的情况），系统按“Journal上的 Code + 四位年份/两位月份/四位序号”规则编号。**如果人为修改了该日记账最近的一个凭证的编号（例如修改了年份），可能会导致新凭证编号不正确（报年份和凭证日期年份不一致的错误）**。

4.  每月每个日记账的第一个会计凭证，系统自动从流水号0001开始编码，此时，可以手工修改凭证号格式及起始流水号，一旦修改，该月后续凭证号都将按新格式自动生成（凭证审核时自动生成凭证号）。

5.  系统提供了同一个日记账，月末按日期顺序重新编号的功能。

6.  会计凭证上增加了一个字段：Post Automatically， 如果勾选，表示，到了会计记账日期，系统自动审核该凭证。
