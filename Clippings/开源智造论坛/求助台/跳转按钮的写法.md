# 跳转按钮的写法

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:葛忠彪 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/964>

链接: https://pan.baidu.com/s/1TZHCZbyV3vfohoLhXJMkXA?pwd=esc1 提取码: esc1

跳转到tree视图的写法：

domain=[('id','=', record.move_id.id)]

action = env.ref('account.action_goto_move_journal_line').read()[0]

action['domain'] = domain

ref对应跳转后的tree视图的动作的外部ID，domain条件视单据关联需做修改

跳转到form视图的写法

```python
for i in records:

  move_id = i.move_id

  action = {'res_model': 'account.move',

            'type': 'ir.actions.act_window',}

  if move_id:

    action.update({

                'view_mode': 'form',

                'res_id': move_id.id,

            })
```

res_model和res_id的参数视单据关联需做修改
