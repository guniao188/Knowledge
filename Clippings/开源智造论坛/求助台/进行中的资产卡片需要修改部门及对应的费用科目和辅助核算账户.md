# 进行中的资产卡片需要修改部门及对应的费用科目和辅助核算账户

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:符赛红 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/951>

**业务场景：**

固定资产在折旧中之后，用户无法修改会计的费用科目和辅助核算项，实际业务中有时会出现一个资产部门的转换，故会涉及费用科目及辅助核算项的调整，而odoo原生的功能中，并不能支持【进行中】的资产修改，并且因为已有折旧的会计分录过账，也无法重置或取消。故进行配置增加这个功能的扩展。

**实现方法配置：**

****

1、在【资产】菜单的form视图中，增加继承视图：

![[1-951-00c6f214.png]]

account.asset.form customization

代码：

```python
    {"readonly": [["state","=","close"]]}

    {"readonly": [["state","=","close"]]}

    {"readonly": [["state","=","close"]]}
```

增加用户点的动按钮及逻辑方法：

![[1-951-a67f0de4.png]]

配置测试通过的代码写法：注意缩进

```python
for r in records:

  if r.depreciation_move_ids and r.state == 'open':

    for x in r.depreciation_move_ids:

      if x.state == 'draft':

        for y in x.line_ids:

          if y.account_id.user_type_id.id ==15:

            tags = [(6, 0, [t.id for t in r.analytic_tag_ids])]

            y.write({'account_id':r.account_depreciation_expense_id.id,

                    'analytic_account_id':r.account_analytic_id.id,

                    'analytic_tag_ids': tags

            })
```
