# 列表编辑视图中上下箭头键实现同一列焦点上下移动

[https://gitlab.com/oscg-china/extra-addons/-/tree/17.0/arrow_key_in_list_view](https://gitlab.com/oscg-china/extra-addons/-/tree/17.0/arrow_key_in_list_view)

【业务背景】

本贴功能实现参考此模块： [销售订单搜索更多的弹窗增加多选功能sale_products_multi_add](http://www.thinkltd.cn/forum/2/sale-products-multi-add-3628)

华霆电器的需求中，业务员每天要处理很多客户报价，业务员对于报价商品、数量的快速录入非常看重。SO上批量添加产品后，默认数量都是1，需要逐行录入数量。此时，希望可以通过上下箭头键在数量列上下移动，快速录入数量。

![[1-775-d09e3162.png]]

【实现方法】

Odoo14中，文件 OSCGODOO14\source\addons\web\static\src\js\views\list\list_editable_renderer.js ，方法 _onNavigationMove: function (ev) { 中，增加对 up, down 事件的处理。处理代码如下：

```python
            case 'up':

                var currentFieldIndex = this.currentFieldIndex;

                var currentRow = this.currentRow;

                this._selectCell(currentRow-1, currentFieldIndex, {wrap: false});

                break;

            case 'down':

                var currentFieldIndex = this.currentFieldIndex;

                var currentRow = this.currentRow;

                this._selectCell(currentRow+1, currentFieldIndex, {wrap: false});

                break;
```
