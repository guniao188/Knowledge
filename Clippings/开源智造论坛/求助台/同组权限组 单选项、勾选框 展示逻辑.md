# 同组权限组 单选项、勾选框 展示逻辑

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:施叶寒 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/717>

背景：

```python
    用户form视图里，权限组会根据category_id进行分组，共有2中展示方式。

        1：系统管理 权限组分类， 把同组的权限组集成在一个下拉框里；

        2：额外的权利 权限组分类，把同组的权限组独立地用勾选框展示。
```

核心逻辑：

    集中的单选框是一种特殊的展示方式。如果 同组的权限组 可以用仅用一个权限组 来描述所有情况，ODOO就会采用单选框让用户进行选择。

举例说明：

    现在共有 A,  B,  C  3个权限组，其中B包含A，C包含B。这种简单的单项包含关系可以用一个权限组来解释所有情况。

![[1-717-2cf8ea65.png]]

```python
    如果此时同组新增一个权限组D，和其他权限组没有任何关联关系。此时之前的简单单项包含关系就不存在了。

    举例：如果想要一个用户拥有A, D权限组，那必须给他同时勾选A, D权限组。此时单选框就不适用这种场景。所以ODOO只能用独立的勾选框分别展示所有的权限组。
```

总结：

```python
    这个同组的单选框逻辑 可以直观地展示了同组权限组的关联关系。背后的代码逻辑也写的很好。

    参考res_users的get_groups_by_application方法，尤其是linearize子方法。
```
