# 单据明细行的【序号】编码1，2，3的代码示例

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:符赛红 | 2024-03-19
> <http://www.thinkltd.cn/forum/1/1-2-3-956>

老肖提供示例

odoo中自带的明细行的【序号】总是默认是10，需要人工填写，才可以有这个序号值，但时常我们打印或是界面上显示上需要按行数显示这个序号，那么可以这么操作：

第一步，先在明细行增加int类型字段；

第二步，可以在界面显示或不显示，只是打印调用；

第三步，写个服务器动作，示例代码如下：

num = 2
```python
for line in record.order_line:
  line.write({'sequence': num})
  num = num + 2
```

## 补充/答案 1

建议编号要跳过节和说明
```python
     @api.depends('sequence')
        def _compute_sequence_no(selfs):
            selfs = selfs.order_id.order_line
            for self in selfs:
                a = 1
                line_ids =  self.env['sale.order.line'].search([('order_id','=',self.order_id.id),('display_type','=',False)],order="sequence,id")
                for line in line_ids:
                    if line.id != self.id:
                        a +=1
                    else:
                        break
                self.sequence_no = a
```
