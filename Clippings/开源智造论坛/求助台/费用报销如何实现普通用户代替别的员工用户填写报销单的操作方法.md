# 费用报销如何实现普通用户代替别的员工用户填写报销单的操作方法

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:符赛红 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/864>

系统源码中有限制，普通用户只能填写员工为绑定了自己的用户账号的报销单，无法代替别人进行费用报销，查了源码，系统并非记录规则导致的不能下拉选择到其他用户，而是py文件中就有方法加了domain，界面上xml的视图中domain条件反写也不会生效。

![[1-864-a9895be8.png]]

解决方法如下：

1、更改了源码上的方法限制：

需求：普通用户要能代替别人进行费用报销 更改的源码
文件目录：/opt/odoo/odoo15/odoo-server/addons/hr_expense/models/hr_expense.py
第63行的方法拿掉了限制domain=lambda self: self._get_employee_id_domain(),
第864行的方法拿掉了限制, domain= lambda self: self.env['hr.expense']._get_employee_id_domain()

2、界面上记录规则需要调整：

内部用户需要看自己创建的，以及自己的费用报销单和明细

针对【团队审批者】权限组的权限，表hr.expense

['|', '|', '|', '|',
```python
                ('employee_id.user_id', '=', user.id),('create_uid', '=', user.id),
                ('employee_id.department_id.manager_id.user_id', '=', user.id),
                ('employee_id.parent_id.user_id', '=', user.id),
                ('employee_id.expense_manager_id', '=', user.id)]
```

针对【团队审批者】权限组的权限，表hr.expense.sheet

['|', '|', '|','|',
```python
                ('employee_id.user_id', '=', user.id),('create_uid', '=', user.id),
                ('employee_id.department_id.manager_id.user_id', '=', user.id),
                ('employee_id.parent_id.user_id', '=', user.id),
                ('employee_id.expense_manager_id', '=', user.id)]
```

针对内部用户的权限规则调整，表hr.expense

['|',('employee_id.user_id', '=', user.id),('create_uid', '=', user.id)]

针对内部用户的权限规则调整，表hr.expense.sheet

['|',('employee_id.user_id', '=', user.id),('create_uid', '=', user.id)]
