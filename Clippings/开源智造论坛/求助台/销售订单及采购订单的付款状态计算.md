# 销售订单及采购订单的付款状态计算

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:符赛红 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/892>

通常在SO或PO列表上，想看到该SO或PO的销账款项的状态，如果不想复杂的计算和写代码，可以界面上增加计算型字段：

销售订单模型上增加布尔型字段：x_paid

依赖于：invoice_ids.state,invoice_ids.payment_state

计算方法：

```python
for record in self:
  if record.invoice_ids:
    for x in record.invoice_ids:
      if x.payment_state == 'paid'and x.state !='cancel':
        record['x_paid']= True
```

只要发票上会计有核销了，就会更新该状态到SO或PO的列表，分别在sale.order和purchase.order上添加这二个字段。

采购订单上增加布尔型字段：x_is_invoiced_paid
依赖于：invoice_ids.state,invoice_ids.payment_state
计算方法：

```python
for record in self:
  if record.invoice_ids:
    for x in record.invoice_ids:
      if x.payment_state == 'paid'and x.state !='cancel':
        record['x_is_invoiced_paid']= True
```
