# Odoo16会计报表配置详解

Odoo16的会计报表配置功能，比之前版本增强很多，下文详解

1.  报表配置

一、报表配置

- 明细行：报表上的明细行配置

- 列：报表每行显示的列的配置（一行可以有多列数据）

- 选项：报表的筛选条件配置（如会计期间、科目类型等）

- 自定义报表：继承模型 account.report.custom.handler ，自己开发报表逻辑，报表上的字段 custom_handler_model_id，指向自定义的报表逻辑模型。参考示例 系统自带的现金流量表，代码文件  account_reports\models\account_cash_flow_report.py 方法 def _get_report_data

![[1-odoo16-973-2436acbf.png]]

- 列-名称：该列列头显示标签

- 列-表达标签：该列内部名称（内部计算或内部）

- 列-人物类型(figure_type)：翻译不当，应为数据类型，选项有 金额、整数、日期、浮点数等

- 列-可排序：该列支持双击排序

- 列-如果为零则空白：值为零时候不显示（显示空白）

## 补充/答案 1

二、报表明细行

![[1-odoo16-973-20347b51.png]]

- 主线(parent_id)：翻译不当，应为上级明细行。本行金额系统自动汇总到上级明细行对应的列上

- 分组：以英文逗号隔开的分组字段。分组字段来自会计分录（account.move.line）模型。例如，填写 account_id,move_id ，报表上显示按会计科目的分组，点击展开后，再显示按会计凭证的分组。

- 动作：点击明细行，自动跳转到此处选定的动作（Action）。

- 等级：明细行的显示级别，0,1,2,3等不同级别。级别越高，字体越粗，明细行的下划线也越粗。

- 代号：本明细行的代码，别的明细行可以使用该代码引用本明细行的列值，如 PL_01.balance_year

- 可折叠的：勾选表示，本明细行左边显示展开/收拢的图标

- 打印到新页：从本行开始，换行打印（导出到PDF时候）

- 如果为零则隐藏：如果本行的列值为0，则不显示本行。

- 列值：明细行可以配置多个列，列的标签对应报表上的列的“表达标签（内部列名）”

四、列计算引擎

![[1-odoo16-973-6ca0d392.png]]

- Odoo域：公式处填写Domain表达式，系统按此表达式筛选 account.move.line，子公式处可以填写 sum, sum_if_pos, sum_if_neg, count_rows 。sum表示汇总求和，sum_if_pos 表示汇总后为正数，则取汇总值，为负数则取0 。sum_if_neg 和 sum_if_pos 相反，count_rows表示符合条件的account.move.line 的个数。示例 [('account_id.account_type', '=', 'income')]

- 税标准：填写适用范围为“税” 的科目标签（account.account.tag），系统按此标签匹配account.move.line 的字段 tax_tag_ids 。子公式不填。

- 聚合其他公式：报表上其他明细行加减汇总计算此明细行值。示例：OPINC.balance + OIN.balance - COS.balance - EXP.balance - DEP.balance

- 账号代码前缀：用科目代码表示汇总值。示例 6602 + 530101 + 6421  表示 科目代码以 6602 开头，530101 开头，6421  开头的account.move.line余额汇总。123\\1234,1236) 表示以123开头的分录，排除 1234,1236开头的分录。123D\\1235) + 56 - 416C表示123开头的分录的借方（Debit），排除12345开头的分录，加上56开头的分录的余额，减去416开头的分录的借方（Credit）。子公式不填。

- 外部价值：翻译有点问题，External Value，外部值。其值在报表上输入，输入后自动存储在模型 account.report.external.value 中。公式可填值为：most_recent 和 sum ，子公式示例值 editable;rounding=2 。报表显示效果如下图

- 

![[1-odoo16-973-608ceecb.png]]

- 自定义Python函数：公式处填写模型 account.report 或 account.report.custom.handler 的方法，系统调用该方法获取列值。参考示例：系统自带的账龄表的计算逻辑，代码文件 account_reports\models\account_aged_partner_balance.py 方法 def _report_custom_engine_aged_receivable .
