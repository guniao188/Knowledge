# 批量上传产品文档并关联到产品附件

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/791>

【业务背景】

1.  产品的设计图纸等文档资料，希望批量上传到系统，且自动关联到对应的产品（作为产品档案的附件）

2.  采购订单明细行上希望可以一键跳转到产品文档画面，因为下单时候需要下载产品文档发给供应商

【解决方案】

1.  Odoo 14中，文档管理可以批量上传文档，方便产品文档电子化管理：[参考这里](http://www.thinkltd.cn/forum/2/question/odoo14documents-1341)

2.  文档上传后，写一个服务器动作，批量将文档关联到对应的产品。要求是，产品文档名称的格式必须是：产品编码_序号.文件后缀。如此，服务器动作从文档名称中解析出产品编码，按产品编码搜索产品，而后将文档关联到该产品附件。[参考这里](http://www.thinkltd.cn/forum/1/question/1514)

3.  文档关联产品的服务器动作参考代码如下

4.

![[1-791-2a54412d.png]]

product_folder_id=env.ref("documents_product.documents_product_folder")

for doc in records:

  #从文档名称中解析产品编码，假设名称构成是 产品编码_序号.文件后缀，且产品编码中不含.和_

```python
  doc_name, ext = doc.name.split(".")

  product_code, seq = doc_name.split("_")
```

  #用产品编码搜索产品

  product = env["product.template"].search([("default_code", "=", product_code)], limit=1)

  #将文档关联到搜索到的产品附件

```python
  if product:

    doc.write({"res_model":"product.template", "res_id":product.id, "folder_id":product_folder_id.id})
```

## 补充/答案 1

【采购明细行一键跳转到产品文档】

1.  增加一个服务器动作，该服务器动作跳转到产品文档画面

2.  采购明细行上增加按钮，点击跳转到产品文档

服务器动作代码：

![[1-791-508290d2.png]]

domain=[('res_model','=', 'product.template'),('res_id','=', record.product_id.id)]

action = env.ref('documents.document_action').read()[0]

action['domain'] = domain
