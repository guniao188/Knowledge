一、清理业务数据的服务器动作：

可以在任意菜单记录下勾选执行该动作，**请在清理完成后，务必每个菜单检查是否有清理完成，用最高权限看各个菜单及报表是否还有统计数据存在。（一旦上线，有些数据就很难根治了，尤其是与成本相关，影响深远）**

该动作中的内容：**注意哦，如果有些数据用户提出要保留，还要将这个[ ]里的一些数据表移去，避免误删，还有注意要保留下来的数据表里的message哦，message是一个独立表，这个示例脚本中是含有所有message清除的，一旦清理全部没有了，如果有个别数据要保留，就得这个表也要手动处理。**

**即这里面的示例，并非一成不变，是需要依客户提出的清理要求，适当调整处理后才可以执行。****

def remove_data():
  for line in to_removes :
    obj_name = line[0]
    obj = env.get(obj_name, False)
    if obj != False:
      sql = "delete from %s" % obj._table
      env.cr.execute(sql)
  return True

二、清理业务数据后，需要将单据的编码重置为1开始重新编号

![[1-v15-846-87280a38.png]]

代码示例：

```python
for r in records:
  r.write({'number_next_actual':'1'})
  if r.date_range_ids:
    for m in r.date_range_ids:
      m.write({'number_next_actual': '1'})
```

第三，需要将用户标为员工，以及公司主体关联，删除不必要的测试数据

![[1-v15-846-3450ab77.png]]

```python
for r in records:
  r.write({'employee': True})
  r.write({'customer_rank': '0'})
```

大家特别注意：

如果用到多公司，请务必使用**【超级管理员】**来执行删除和重置单据，避免其他公司抬头要依次处理和遗漏；

另外特别注意要手动删除基础数据，尤其是partner的处理，还有产品的处理，系统有默认的模块中引用的数据或用户登录，公司主体引用的数据记录

再者，得注意一些被****存档****的基础数据，也会被漏删，注意过滤器里处理。

切成高级管理员：

PS：再三强调，如果该客户涉及多公司，涉及进销存，清理完成后

**产品基础数据上的期初成本，在盘点验证前，务必再刷新一遍为期初上线时的实际成本。**

**该金额需要与会计期初库存商品存货余额相吻合。**
