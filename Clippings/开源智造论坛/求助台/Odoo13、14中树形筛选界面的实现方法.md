## 补充/答案 1

odoo13也是可用的

  另外图标设置图标  icon=“”    图标链接：https://fontawesome.dashgame.com/    记得前面加上fa-， 类似于这样：icon="fa-address-book"

增加筛选条件（以下案例是销售订单上只过滤出客户的代码）：

```python
    @api.model
    def search_panel_select_range(self, field_name):
        res = []
        result = super().search_panel_select_range(field_name)
        if field_name == 'partner_id':
            for each in result['values']:
                if self.env['res.partner'].browse(each['id']).customer_rank > 0:
                    res.append(each)
            result['values'] = res
        return result
```
