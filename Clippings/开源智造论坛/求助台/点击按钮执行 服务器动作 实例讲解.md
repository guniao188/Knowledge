# 点击按钮执行 服务器动作 实例讲解

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/285>

【案例说明】PO表单上增加按钮“抓取SO说明”，点击按钮，执行 服务器动作: 根据PO的源单据查找SO，找SO上的产品相同的明细行，取SO明细行的 说明 列，添加到PO明细行的说明列。

【实现原理】1）编写 python代码的服务器动作，根据PO的源单据查找对应SO，找SO后，再根据PO明细行的产品，查找SO上产品相同的明细行，取SO明细行的 说明 列，添加到PO明细行的说明列。 2）PO表单上添加按钮，按钮 name 为 服务器动作 id，按钮 type 为  action .

## 补充/答案 1

服务器器动作代码示例：

```python
    if record and record.state == 'draft' and record.origin:
        so_ids = env['sale.order'].search([('name', '=', record.origin.strip())])
        if so_ids:
             so = so_ids[0]
             for pol in record.order_line:
                  line = so.order_line.filtered(lambda l:l.product_id.id == pol.product_id.id)
                  if line:
                      pol.write({'name': "%s\n销售说明：%s" % (pol.name, line.name)})
```
