# 无法进入环境情况下卸载模块方法

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:赵晨 | 2023-05-30
> <http://www.thinkltd.cn/forum/1/3726>

在安装模块后，环境报500错误无法登录卸载，可以通过SSH命令来卸载模块

输入命令ps aux | grep python 找到odoo进程并复制，然后停止odoo进程

示例：

/opt/odoo/odoo16/odoo16-venv/bin/python /opt/odoo/odoo16/odoo-server/odoo-bin shell -c /odoo/odoo16/custom/addons/odoo-server16.conf -d odoo_demo

bin后加 shell conf 后加 -d + 环境数据库名，进入数据库python命令环境

record = env['[ir.module.module'].search([('name','ilike','account_accountant')])](https://ir.module.module%27%5D.search%28%5B%28%27name%27%2C%27ilike%27%2C%27account_accountant%27%29%5D%29/)
record.button_immediate_uninstall()

输入以上指令即可完成卸载，account_accountant 可以替代为想卸载的模块名， button_immediate_uninstall()为卸载命令，写法类似服务器动作。

## 补充/答案 1

服务上直接移走模块，然后可以登录，再进应用里卸载模块也可以吧
