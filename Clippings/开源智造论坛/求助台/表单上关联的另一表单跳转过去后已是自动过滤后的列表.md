# 表单上关联的另一表单跳转过去后已是自动过滤后的列表

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:符赛红 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/409>

示例代码：需要在后台py里面定义：

```python
def action_view_posted_loans(self):
        action = {
            'name':'还款单',
            'res_model':'account.loan',
            'view_type':'form',
            'type': 'ir.actions.act_window',
        }
        loans = self.posted_loan_ids
        if len(loans) > 1:
            action.update({
                'view_mode':'tree, form',
                'domain':[('id','in',loans.ids)],
            })
        elif len(loans) == 1:
            action.update({
                'view_mode':'form',
                'res_id':loans.id,
            })
        else:
            action = {'type': 'ir.actions.act_window_close'}
        return action
```
