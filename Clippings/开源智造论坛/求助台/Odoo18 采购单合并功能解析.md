# Odoo18 采购单合并功能解析

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:葛忠彪 | 2025-06-11
> <http://www.thinkltd.cn/forum/1/odoo18-4047>

Odoo18里，在采购询价单列表界面，可以多选状态是草稿、发送中的采购询价单进行合并，逻辑如下

1.系统判断这些单据状态都是草稿（询价）或者发送中

2.系统取date_order最早的单据，最为目的单据，其他单据视作来源单据

3.对来源单据的产品行做循环，在目的单据里找相同产品、单位、单位、包装、包装数量、折扣、且交期和源明细行相差一天内的明细行，这样会有3个情况

```python
  3.1 目的单据里找到多个明细行，先处理目的单据里的明细行，直接把目的单据里这些明细行数量累加，并只保留第一行，然后再把来源行和目的行数量累加更新给目的行（的第一行），且保留2者单价更小的那一行的单价

  3.2  目的单据只找到一个明细行，直接把来源行数量累加给目的行，且保留2者单价更小的哪一行的单价

  3.3  找不到目的行，直接把来源行的order_id修改成目的采购单
```

这个做法从常规业务角度出发不会有问题，但是遇到特殊场景，同一个产品，因为各种原因单价不同分行时，要利用折扣字段来区分（不能直接用单价区分），不然用到合并功能时这几行就会合并，且取最低单价的哪一行的单价，就不符合源数据的业务场景了
