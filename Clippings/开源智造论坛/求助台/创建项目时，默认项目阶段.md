# 创建项目时，默认项目阶段

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:葛忠彪 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/917>

思路：

在项目上增加布尔型字段，定义哪些项目是模板项目

在项目上增加manytoone字段，指向模板项目

做自动的动作，将本项目的阶段赋值为本项目里选择的模板项目的阶段

```python
for i in records:

  if i.default_project and not i.type_ids:

    project =i.env['project.project'].search([('id', '=',i.default_project.id )])

    i.write({'type_ids': [(6, 0, project.type_ids.ids)]})
```
