# 服务器动作搜索关联产品并跳转到列表视图显示示例

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/339>

【需求】根据阀门的属性值，搜索关联的阀门部件（名称含有 “毛坯” 字样），显示部件产品列表

【实现方法】写一个 服务器动作 实现，代码如下：

# Available variables:
#  - env: Odoo Environment on which the action is triggered
#  - model: Odoo Model of the record on which the action is triggered; is a void recordset
#  - record: record on which the action is triggered; may be void
#  - records: recordset of all records on which the action is triggered in multi-mode; may be void
#  - time, datetime, dateutil, timezone: useful Python libraries
#  - log: log(message, level='info'): logging function to record debug information in ir.logging table
#  - Warning: Warning Exception to use with raise
# To return an action, assign: action = {...}
```python
domain = [ ('name', 'like', '毛坯') ]
for v in record.attribute_value_ids:
        if v.name in ['PB', 'PC']:
                continue
        domain.append( ('description', 'like', v.name) )
if record.name.find('阀门'):
        domain.append( ('description', 'like', record.name[:-2]) )
```

action = env.ref('stock.stock_product_normal_action').read()[0]
action['domain'] = domain
