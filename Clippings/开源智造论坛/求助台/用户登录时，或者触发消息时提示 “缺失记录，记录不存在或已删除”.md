# 用户登录时，或者触发消息时提示   “缺失记录，记录不存在或已删除”

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:葛忠彪 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/960>

![[1-960-03471bef.png]]

此部分内容为个人猜测，仅供参考

【推测是其他单据触发了消息，用户没有及时查看消息

而后续其他用户删除了此单据，导致当前用户登录时提示有未读消息，而消息又指向不存在订单订单导致的】

目前可以解决问题的方法是清空整个massage模型，但是这样一来其他的消息也没有了

暂时无法定位准确的报错消息的ID，用回复人、至、res_id搜索都无法定位，有什么好办法吗

## 补充/答案 1

会不会是单据（截图单据是 account.move, id 231376）被删除了，但该单据关联的Message没删除。如果是这样，只要找一下message上的res_id = 231376, model = 'account.move' 的message，把该部分message删除可能就好了。

## 补充/答案 2

经测试，在网页端没有域限制没有多公司限制没有记录规则限制就是不显示对应的记录
解决方案是 需要进数据库，通过SQL预计,用res_id = 231376, model = 'account.move'去搜索和删除
