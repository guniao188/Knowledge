# 企业版破解方法

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:肖相扶 | 2025-06-16
> <http://www.thinkltd.cn/forum/1/219>

1.  文件addons\mail\models\update.py 方法 def _get_sys_logs( ) 直接 return {"messages": None}

2.  如果数据库已经过期了，则需要通过plsql 修改表 ir_config_parameter，key值database.expiration_date、database.create_date 的日期值为足够大：select value from ir_config_parameter where key='database.expiration_date'

3.  破解原理：方法 def _get_sys_logs( ) 从Odoo官方网站 'publisher_warranty_url': 'http://services.openerp.com/publisher-warranty/'  获取database的创建时间、到期时间，根据此时间判断是否过期。如果没取到创建时间、到期时间，则取 ir_config_parameter，key值database.expiration_date、database.create_date 的日期

4.  此破解方法适用于11.0， 12.0 的企业版。

5.

## 补充/答案 4

### **odoo13 和12的破解一样！！**

1. 直接更新： update ir_config_parameter set value = '2099-01-01' where key='database.expiration_date';

2. 如果表中没有key='database.expiration_date' 的记录，使用insert插入：
    insert into ir_config_parameter (key,value) values('database.expiration_date','2099-01-01');

3 直接在界面上修改，不需要去到数据库中： 技术->系统参数    创建一条时记录
   database.expiration_date
   2099-01-01

![[1-219-c6c68169.png]]

![[1-219-af5cbd0a.png]]

**4、符补充：**
如果已经过期了，还可以将已过期这个账套里的【计划任务】中id=3的任务设置为False；
update ir_cron set active=False where id=3;
改完【系统参数】上面的创建日期，到期日期之后，
最后还要记得重启一下数据库，以及odoo进程。
