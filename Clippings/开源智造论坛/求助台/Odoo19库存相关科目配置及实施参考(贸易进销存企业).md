# Odoo19库存相关科目配置及实施参考(贸易进销存企业)

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:肖相扶 | 2025-12-15
> <http://www.thinkltd.cn/forum/1/odoo19-4096>

【方案一：基于采购/销售发票自动生成会计凭证】

参考：[Odoo19库存价值/成本计价计算逻辑总结](http://www.thinkltd.cn/forum/1/odoo19-4095)

1.  业务逻辑：
2.  1.  采购核算：采购入库时候不自动生成会计凭证。收到供应商发票后，系统中录入供应商账单，确认供应商账单，系统自动生成会计分录。借记 库存商品、应交税费，贷记 应付账款
```python
    2.  销售核算：销售出库时候不自动生成会计凭证。给客户开发票时候，系统中录入客户结算单，确认结算单，系统自动结算销售收入和销售成本，自动生成会计分录。借记 应收帐款、主营业务成本，贷记 主营业务收入、库存商品、应交税费。
    3.  盘点盈亏核算：系统自动生成会计分录。盘盈借记 库存商品，贷记 待处理财产损益，盘亏借记 待处理财产损益，贷记 库存商品。
    4.  到岸成本分摊：发生费用分摊时候，如进口关税、运费、港杂费等的分摊。系统的到岸成本分摊功能，自动生成会计分录，借记 库存商品，贷记 分摊费用科目
```

3.  配置要点：
4.  1.  产品/分类的库存计价( Inventory Valuation)选择 real_time，成本方法可以是standard、avco或者fifo 。收入科目配置 主营业务收入，费用科目配置 主营业务成本，库存科目配置 库存商品。如此，采购发票确认时候，系统借记 库存科目。销售发票确认时候，系统借记 费用科目，贷记 收入科目、库存科目。
    2.  盘点库位库存科目配置 待处理财产损益。 如此，盘盈盘亏的stock move验证完成时候，系统自动生成盘点会计分录。
    3.  供应商库位和客户库位库存科目留空，不设置。如此，采购入库、销售出库的stock move验证完成时候，系统不生成会计分录。
5.  方案优点：
6.  1.  Odoo19标准功能，无需第三方插件，无需二次开发，可以实现 库存商品、销售收入、销售成本的核算，且销售发票确认时自动核算收入，同时自动核算销售成本。
7.  方案不足：
8.  1.  采购已入库，但尚未收到供应商发票的货物，系统没有生成会计分录，没有纳入 库存商品(或库存暂估)进行核算。此部分货物，库存上有账(采购入库stock move的value、remaining_qty、remaining_value三个字段)，会计上没账(没有生成会计凭证)。
    2.  销售已发货，但尚未开具销售发票的货物， 系统没有生成会计分录，没有纳入 发出商品进行核算。 此部分货物，库存上有账(销售出库stock move的value字段)，会计上没账(没有生成会计凭证)。
    3.  如果供应商欠票太多，而销售却及时开票，则可能出现 库存商品科目余额在贷方的情况。如果出现此种情况，可以根据“方案补足”中的办法，手工做调整分录，调整库存商品金额。
9.  实施争议/注意点：
10. 1.  采购发票价格差异的问题。采购入库，而后收到供应商发票，供应商发票价格和采购订单价格有差异(如因质检缺陷导致结算/开票价格更低)。系统的处理是，采购发票确认时候，系统自动找到对应的采购入库，按发票价格重算入库stock move的价值(value字段)，及剩余价值(remaining_value字段)。如果该stock move已经发生了部分出库(如销售出库)，则之前出库的部分，出库价值(库存商品科目贷方)及出库成本(主营业务成本科目)偏高了，应该按发票价格调减。调减分录为，借记 库存商品，贷记 主营业务成本。
    2.  到岸成本分摊的问题(参考 [odoo19到岸成本分摊临时处理方案](http://www.thinkltd.cn/forum/1/odoo19-4091) )。和发票价格差异类似，采购入库后，发生了费用分摊，入库stock move的价值(value)变高了。系统的处理是，加上分摊金额，重算入库stock move的价值(value字段)，同时自动生成分摊的会计分录(借记 库存商品，贷记 分摊费用科目)。但系统生成的会计分录，只会计算在库的部分，已出库的部分不计。例如，入库stock move数量为10件，分摊费用10元(每件摊1元)，已经出库了7件(在库的还剩3件)，系统产生会计分录时候，借记 库存商品 3元，已出库的7件的分摊金额不记入库存商品科目。和发票价格差异类似，该stock move已经出库的部分，出库成本(主营业务成本科目)偏低了，应该按分摊金额调高。调高分录为，借记 主营业务成本，贷记  分摊费用科目。思考：此处为什么不用调高库存商品科目？
11. 方案补足(二开点参考)：
12. 1.  增加已采购入库但尚未到票的stock move的价值及剩余价值查询报表。月末，会计人员可以查询此报表，根据报表金额，手工做调整分录调整库存价值。
```python
    2.  增加已销售出库但尚未开票的stock move的价值及剩余价值查询报表。 月末，会计人员可以查询此报表，根据报表金额，手工做调整分录调整库存价值。
    3.  供应商账单上，增加一键查询功能：供应商账单确认的时点，如果账单关联的入库stock move，存在已出库的情况，一键查询已出库stock move的价值和剩余价值(账单确认时点的剩余价值)。账单处理人员，根据查询结果，手工做调整分录，调整库存商品和主营业务成本科目。
    4.  到岸成本分摊单上，增加一键查询功能：到岸成本分摊单确认的时点，如果分摊单关联的入库stock move，存在已出库的情况，一键查询已出库stock move的价值和剩余价值(分摊单确认时点的剩余价值)。分摊处理人员，根据查询结果，手工做调整分录，调整主营业务成本科目。
```
