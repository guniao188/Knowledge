# V14的币种小数位数一旦有了赁证就不允许修改了，有什么办法调整吗

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:符赛红 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/v14-738>

![[1-v14-738-0b671e8f.png]]

一开始币种设得精度较高，但因为有会计赁证了，现在想中途改回四舍五入到二位小数，但却提示不可以修改，请问是哪里的字段逻辑导致的呢，切换成高级管理员也不可以调整。

如果用sql语句直接修改是否可行？

## 补充/答案 1

Odoo14修改币种小数精度时候，系统增加了检查：如果该币种已经有会计分录，报错，不允许减少小数精度。但通过SQL修改的话是可以绕开该检查，修改小数精度的。该检查逻辑的代码参见：ODOO14\source\addons\account\models\res_currency.py   方法 def write(self, vals):

SQL修改的话，注意连小数位数字段“decimal_places” 一起修改掉。界面上修改时候，系统自动计算decimal_places字段值，SQL修改的话，绕过了Odoo，不会自动计算 decimal_places 的值，所以要SQL一并修改。

## 补充/答案 2

按顺序执行sql语句更改，才会让历史的赁证生效也变成二位数：

先执行：

 update res_currency set decimal_places='2' where id=7;

id=7是指CNY币种

update res_currency set rounding='0.0100' where id=7;
