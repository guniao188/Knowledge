# V14配置成本权限涉及的要点

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:符赛红 | 2025-07-17
> <http://www.thinkltd.cn/forum/1/v14-880>

对于成本的值，一般企业会提出要设置权限进行控制，除了管理层，会计，采购会要看到成本金额，其他部门的用户会要进行限制。

通常配置的要点如下：

1、为了灵活配置，最好另行增加一个自定义权限组，并记住它的ID值

成本管理

![[1-v14-880-7689622b.png]]

2、用第一步产生的ID，到外部ID数据表中，创建一个自定义的外部ID

外部ID为account.cost_group_manager

![[1-v14-880-d46c24be.png]]

3、产品表product.template的权限控制，增加继承视图

form视图

tree列表视图

可以各上模块下的链接点点，看看是否还能看到成本

继承form视图Odoo Studio: product.template.product.form customization  并记得在【采购page页面上的供应商价格表】也要设置个权限，只有采购用户可以看到，避免普通用户看到

```python
    account.cost_group_manager

    purchase.group_purchase_user,account.cost_group_manager
```

V14代码：

```python
    account.cost_group_manager

    purchase.group_purchase_user,account.cost_group_manager

    purchase.group_purchase_user,account.cost_group_manager
```

可以关闭message

12、客户发票如果是启用saxson，那么发票上也会有成本

如果销售也会操作创建生成客户发票，那么这里测试时请留意，对于会计赁证的page页面上，增加个权限组即可。

继承：account.move.form

Odoo Studio: account.move.form customization

代码：

    account.cost_group_manager,account.group_account_user

13、其他报表的地方

比如热点视图，分析报表等地方，一般本身是管理员才看的，所以一般不会涉及成本权限，但也有个别客户会要控制，那就注意将视图里加个权限组，不让这些不能看的用户看到这个模型的这类视图也可以哦。
