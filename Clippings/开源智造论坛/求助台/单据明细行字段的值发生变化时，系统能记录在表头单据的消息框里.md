# 单据明细行字段的值发生变化时，系统能记录在表头单据的消息框里

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:葛忠彪 | 2024-01-17
> <http://www.thinkltd.cn/forum/1/3868>

例如采购单价发生变化时，系统虽然会记录订单金额的变化，但是看不出具体哪一行单价发生变化还是数量发生变化

可以参考采购订单模块，收货数量发生变化时的方法，具体逻辑为

订单上的write方法里，如果发现收货数 qty_received 发生变化，则执行_track_qty_received方法
if 'qty_received' in values:
for line in self:
line._track_qty_received(values['qty_received'])

而 _track_qty_received 里会针对明细行的表头产生日志

```python
    self.order_id.message_post_with_view(),同时又预置了消息模板 track_po_line_qty_received_template，通过传参数实现消息留痕

    def _track_qty_received(self, new_qty):
        self.ensure_one()
        if new_qty != self.qty_received and self.order_id.state == 'purchase':
            self.order_id.message_post_with_view(
                'purchase.track_po_line_qty_received_template',
                values={'line': self, 'qty_received': new_qty},
                subtype_id=self.env.ref('mail.mt_note').id
            )

    id="track_po_line_qty_received_template">

            The received quantity has been updated.

                t-esc="line.product_id.display_name"/>:
                Received Quantity: t-esc="line.qty_received" /> -> t-esc="float(qty_received)"/>
```
