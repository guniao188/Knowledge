# 专项扣除/代扣代缴等工资项的配置方法

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/933>

1.  Salary Attachments功能（hr.salary.attachment）：菜单 Payroll --> Contracts --> Salary Attachments 。此表单配置代扣代缴的工资项目。
    每个月，系统创建工资单（hr.payslip）时候，系统自动查找该员工的，状态为运行中的，开始日期小于工资当月月末的代扣项，自动添加到工资单的Other Inputs 。

2.  系统预置了三种代扣代缴类型(hr.salary.attachment 的字段 deduction_type)：Attachment of Salary（扣押工资）, Assignment of Salary（转付/代付工资）, Child Support（子女抚养费代扣） 。此三种类型对应的Other Inputs Code（hr.payslip.input.type）为 ATTACH_SALARY，ASSIG_SALARY，CHILD_SUPPORT 。对应的工资计算规则（hr.salary.rule）Code也是ATTACH_SALARY，ASSIG_SALARY，CHILD_SUPPORT

3.  系统内部运作逻辑是工资单（hr.payslip）查找hr.salary.attachment，对应地创建Other Inputs，工资规则上提取相应Code的Other Inputs Code计算扣除金额。

4.  如果要增加一种新类型的hr.salary.attachment，二开方法参考如下：1）hr.salary.attachment字段deduction_type 增加一个新选项；2）代码文件 OSCGODOO15\source\enterprise\hr_payroll\models\hr_payslip.py，继承方法 def _get_attachment_types(self)，增加新类型的Other Inputs Code的对应关系；3）增加对应的Other Inputs Code，以及相同Code的工资计算规则（hr.salary.rule）

5.  销售提成等绩效工资也可以采取类似方法二开：1）新增一个销售提成表单，字段包括员工、开始日期、结束日期、提成金额、对应的Other Inputs 类型；2）工资单创建时候，查找销售提成表，自动创建Other Inputs ；3）配置销售提成的工资计算规则。
