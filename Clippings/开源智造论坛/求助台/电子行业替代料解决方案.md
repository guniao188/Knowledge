# 电子行业替代料解决方案

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/646>

【业务背景】

1.  电子行业，有20% - 50%的物料，如电容器，存在替代料关系。也就是说，BoM上的某个电容器，可以用A品牌的，也可以用B品牌，每个品牌又可以有多个供应商；

2.  替代料关系，有些成熟的物料，不同品牌不同供应商的料，是完全替代关系，也就是说，可以任意替代、完全替代、无差别；

3.  部分替代的情况，例如，之前存在“物料A”，有A1、A2、A3三个完全替代料（三个供应商）。新研发了产品B，该产品的某“物料B”经验证可以用A1，但不可以用A2、A3，另外经研发验证，还可以用A4 （之前的产品因未经验证，不可以用A4）。

4.  仓库管理时候，是对物料A1、A2、A3、A4进行管理，包括入库、存放、出库、盘点、查库存等，都是针对A1、A2、A3、A4进行管理。生产计划人员计划时候，是针对“物料A”、“物料B”进行物料计算。例如，产品A生产计划时候，计算“物料A”的需求量、库存量、缺口量。“物料A”的库存量实际是A1、A2、A3的库存加总（注意不含A4），缺口采购时候，采购单上采购的是A1、A2或A3（注意不是“物料A”）。同理，产品B生产计划时候，计算的是“物料B”的需求量，“物料B”实际包含A1、A4 。

【模块设计】

1.  新开发模块 mrp_substitutions

2.  该模块在物料的供应商(product.supplierinfo)上增加字段：替代料（substitution_id，many2one到product.product）、品牌。

3.  解决思路：a. 系统中定义实体物料：A1、A2、A3、A4，虚拟物料“物料A”、“物料B”。b. “物料A”的供应商(product.supplierinfo)上，替代料(substitution_id)字段维护A1、A2、A3，“物料B”的供应商(product.supplierinfo)上，替代料(substitution_id)字段维护A1、A4 。c. BoM表上，使用虚拟物料“物料A”、“物料B”，不使用实体物料 A1、A2、A3、A4。d. 虚拟物料“物料A”、“物料B”的库存计算规则修改成：在手库存 = 其包含的替代料的在手库存之和，预测库存 = 其包含的替代料的预测库存之和。e. MRP运算时候，系统基于BoM展开MO的原料需求（投料）的Stock Move，Stock Move confirm时候，如果其product_id是虚拟产品，则检查该虚拟物料的替代料(substitution_id)库存。以“物料A”为例：
```python
           1) 先创建A1的投料Stock Move，需求数量是“物料A”的需求数量。
           2) 如果A1的可用数量 = Q1，则需求数量是Q1，同时A1的投料Stock Move的需求数量减少Q1。如果A2的可用数量 < Q1，则需求数量是A2的可用数量，同时A1的投料Stock Move的需求数量减少A2的可用数量。
           4) 继续检查物料A3 。。。
```

4.  MRP逻辑修改点：

5.  1.  MO确认时候，投料Stock Move 替代料数量计算（Stock Move的confirm方法修改）

```python
    2.  MO上修改成品数量时候，引发的原料数量的计算逻辑的修改

    3.  MO上成品报工时候，物料消耗数量的计算

    4.  MO上成品报废时候，引发的物料报废数量的计算

    5.  MO取消时候，投料明细行的取消数量的计算
```
