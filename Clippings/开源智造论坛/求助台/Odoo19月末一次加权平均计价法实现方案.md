# Odoo19月末一次加权平均计价法实现方案

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:肖相扶 | 2025-12-14
> <http://www.thinkltd.cn/forum/1/odoo19-4097>

【 月末一次加权平均成本计价法原理 】

1.  当月出库成本价格，次月初计算。次月初计算每个产品的当月成本价格，当月所有出库，如销售出库、生产领料，都按此价格计算出库成本。
2.  计算方法是，产品的当月期初数量 X 期初成本价格，加该月该产品的所有入库价值，除以该产品的数量(期初数量 + 该月入库数量)，得到当月该产品的成本价格。计算中注意特殊情况：期初数量小于零，则期初数量按零计；期初数量 + 当月入库数量小于等于零，则沿用上月成本价格。
3.  入库价值的各种情况：参与成本价格计算的入库stock move，如何计算其入库价值？分多种情况考虑，下面以采购入库为例说明。
4.  1.  其一，当月入库，且当月收到采购发票，以采购发票价格计算入库价值。
```python
    2.  其二，当月入库，当月未收到发票，以采购订单价格计算入库价值。
    3.  其三，当月入库，当月发生了到岸成本分摊，分摊成本也要计算到入库价值。
    4.  其四，上月入库，本月发生了到岸成本分摊，或者本月收到采购发票，且采购发票价格和上月的采购订单价格有差异。此种情况，到岸成本分摊金额，或者发票差异金额，应该计算到入库价值。
    5.  其五，注意一种极端情况，某产品期初数量为零，当月也没有发生入库，或者期初为负库存，当月入库后期初数量+入库数量仍小于等于零。但当月收到之前月份采购的供应商发票，或者之前月份采购的到岸成本分摊(如收到进口关税发票，而后分摊)。假设发票价格比采购价格低1元，发票数量100件。此种情况，该月入库价值为 -100元，期初数量和入库数量都为零，不能简单地按上述公式计算成本价格。
```

5.  当月入库价值的计算逻辑。
6.  1.  确定哪些入库参与成本价格计算。不是当月所有的入库都参与成本价格计算，如销售退货、盘盈等不应参与成本价格计算。
```python
    2.  确定参与计算的入库价值种类，及每个种类的处理方法。常见的需要考虑三种入库价值，基于采购单价或发票单价的入库金额，发票价和采购价不一致时候的差异金额，发生到岸成本分摊时候的分摊金额。每一笔入库，应把三种价值加起来作为入库价值。
    3.  入库时点，和开票时点，或分摊时点不在同一个月份的处理。入库月份，以采购单价作为入库价值；开票月份，如果存在发票差异金额，差异金额纳入开票月份入库价值；分摊月份，分摊金额纳入分摊月份的入库价值。
    4.  入库时点，和开票时点，或分摊时点不在同一个月份，且开票和分摊月份，该产品期初数量+入库数量小于等于零。此种情况，不计算成本价格，发票差异金额和分摊金额不纳入该月入库价值。此种特殊情况，系统应该标记出来，由人工做调整分录单独处理。
```

7.  自动生成入库价值会计分录，及出库成本会计分录。
8.  1.  入库出库相关的会计分录生成策略，可以有两种，一种是汇总生成，一种是基于stock move逐个生成。
    2.  汇总生成，参考  [Odoo18分类汇总创建存货/出入库会计凭证stock_account_subtotal](http://www.thinkltd.cn/forum/2/odoo18-stock-account-subtotal-4028)。stock move上增加存货分类字段，基于存货分类汇总生成会计分录。注意点，以前月份的发票差异金额，或分摊金额，当月没有对应的stock move，不能基于stock move汇总，要单独汇总。
    3.  基于stock move逐个生成。确定有哪些入库类型和出库类型，每种类型，生成什么样的会计分录(借方科目和贷方科目)。如直发(dropship)是否生成会计分录。可以在虚拟库位上配置出入库科目，基于此配置的科目生成会计分录。注意点， 以前月份的发票差异金额，或分摊金额，当月没有对应的stock move，不能基于stock move生成会计分录，要单独生成会计分录。
9.  历史成本重算，及重新生成会计分录。
10. 1.  系统可能是业务模块先上线，可能三个月后，财务才开始上线。此种情况，可能要从过去三个月开始，逐月计算成本，生成会计分录。生成之后，财务可能发现数据不对，要求取消，修改业务数据，重新计算成本，生成会计分录。

【Odoo19中的实现要点】

1.  配置要点：成本方法配置为avco, 库存计价配置为 periodic。
2.  期初数量：该月1号零点时的在手库存(qty_available)，上下文中指定 to_date 获取 qty_available即可
3.  期初成本价格： 该月1号零点时的成本价格，模型product.product的方法_get_standard_price_at_date() 获取产品的历史成本价格
4.  Odoo19中入库价值的获取方法。以月末时点调用入库stock move的 _get_value()方法，可以获取入库价值。stock move的_get_value()方法：对于入库stock move，该方法获取该stock move的入库价值。该方法先从采购发票获取，没发票则从采购订单获取，如果有到岸分摊，该方法也会获取分摊金额。该方法的参数 at_date 可以指定时点，不同时点获取到的入库价值可能不同。例如，开票前的时点，获取的是采购订单的价格，开票后的时点，获取的是采购发票的价格。到岸分摊前的时点，获取的入库价值不含分摊金额，到岸分摊后的时点，则包含分摊金额。系统时点比较的内部逻辑，发票上取 invoice_date字段进行比较，到岸成本分摊单上取date字段比较。
5.  发票差异和分摊金额的获取方法。入库当月开票及分摊的情况，stock move的 _get_value()方法包含了发票金额和分摊金额。之前月份的入库，当月开票及分摊的情况，需要单独获取发票差异金额，及分摊金额，纳入当月入库价值。
6.  自动创建会计分录，参照stock move 方法 _create_account_move()创建会计分录。
