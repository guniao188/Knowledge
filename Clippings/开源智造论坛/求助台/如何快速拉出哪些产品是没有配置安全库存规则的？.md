# 如何快速拉出哪些产品是没有配置安全库存规则的？

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:符赛红 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/749>

需求背景：

因仓库有设很多不同的区域位置，比如维修区、原料区、质检区、生产部等，而很多的物料或原料需要走采购流程，但不想走MTO，绑定性太强了，从安全库存（哪怕最大最小设为0）触发提醒采购实际缺货的数量来进行采购。但因产品太多，经常会有些产品遗漏配置安全库存规则，导致有些产品有跑出来，有些产品没有跑出来，采购就需要去花很多时间核对，预测为负数的，到底哪些有跑了单哪些还没有出来草稿的采购单。

而且采购如果光赁这些预测为负的来看哪些缺货，得先将那些确认的采购确认掉，才能知道准确的预测数是负的。

## 补充/答案 1

写一个服务器动作，列示所有没有设置再订货规则的产品列表：

# 有再订货规则的产品列表

reorder_ids = env['stock.warehouse.orderpoint'].search([]).mapped('product_id')

# 所有产品的产品列表

all_ids = model.search([('type','=', 'product')])

# 没有再订货规则的产品列表

list_ids = all_ids - reorder_ids

# 产品id列表

ids = [x.id for x in list_ids]

# 跳转到产品列表视图，显示上面查找到的产品id列表

#Odoo 13.0 版本以前的写法：res = env['ir.actions.act_window'].for_xml_id('product', 'product_normal_action')

#Odoo 13.0 版本及以后的写法：

res = env['ir.actions.act_window']._for_xml_id('stock.stock_product_normal_action')

res['domain'] = [('id', 'in', ids)]

action = res

## 补充/答案 2

V11的写法正确的执行完成
需要加在product表上，而非temp表

过滤出来的结果，再加过滤器：非MTO且可库存商品

reorder_ids = env['stock.warehouse.orderpoint'].search([]).mapped('product_id')
all_ids = model.search([('type','=', 'product')])
list_ids = all_ids - reorder_ids
ids = [x.id for x in list_ids]
res = env['ir.actions.act_window'].for_xml_id('product', 'product_normal_action')
res['domain'] = [('id', 'in', ids)]
action = res
