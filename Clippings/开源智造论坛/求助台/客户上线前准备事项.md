# 客户上线前准备事项

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:葛忠彪 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/854>

|     |                                                                    |
|-----|--------------------------------------------------------------------|
| 一  | 正式账套准备                                                       |
| 1   | 测试数据流程跑通                                                   |
| 2   | 历史数据清理、单据序号归0                                          |
| 3   | 权限的配置最终版本落地                                             |
| 　  | 　                                                                 |
| 二  | 基础数据准备                                                       |
| 1   | 产品（原材料、虚拟产品例如费用）                                   |
| 2   | 项目及分析账户清单                                                 |
| 3   | 客户/供应商                                                        |
| 4   | 用户账号                                                           |
| 　  | 　                                                                 |
| 三  | 预计会用到的一些模板（需要会用）                                   |
| 　  | 上线需要的整理的批量导入模板及填写说明，及要能操作导入成功：       |
| 1   | 产品批量导入模板（用不用变体）                                     |
| 2   | 客户/供应商公司及底下联系人批量导入模板                            |
| 3   | 供应商价格表批量导入模板（原材料）                                 |
| 4   | 期初库存盘点单批量导入模板                                         |
| 5   | 期初会计总账科目余额表导入模板                                     |
| 6   | 期初未完成的销售订单批量导入模板                                   |
| 7   | 期初未完成的采购订单批量导入模板                                   |
| 　  | 　                                                                 |
| 四  | 期初数据准备：                                                     |
| 1   | 期初库存（涉及库存的账目，截止日期时点）                           |
| 2   | 期初会计账（科目余额表，含应收应付）                               |
| 3   | 期初的CRM线索商机待跟进的清单                                      |
| 4   | 期初的员工剩余假期                                                 |
| 5   | 员工的合同及薪资公式确认                                           |
| 　  | 　                                                                 |
| 五  | 试运前的跟进和培训                                                 |
| 1   | 依据最新含有期初上线及真实基础数据的账套，进行最后测试的预演和模拟 |
| 2   | 用户操作说明文档，SOP文档整理及分发                                |
| 3   | 用户权限的最终确认，及员工基础资料的维护更新                       |
| 4   | 正式上线动员大会：让各个用户知晓上线及历史数据的截止时点           |
| 5   | 确定正式上线日期，正式上线                                         |
| 　  | 　                                                                 |
| 六  | 数据安全方面的考虑，试运行后，双备份：                             |
| 1   | 备份当前数据库作为启动前模型，做好数据库定期备份，服务器快照       |
| 2   | 云备份服务器云上购买云快照                                         |
| 3   | 服务器自动备份及设置                                               |
| 4   | 数据账套里面的各版块涉及到的保密相关的导入导出权限再检查           |
| 　  | 　                                                                 |
| 七  | 上线                                                               |
| 1   | 实时支持用户上线过程中遇到的问题                                   |
