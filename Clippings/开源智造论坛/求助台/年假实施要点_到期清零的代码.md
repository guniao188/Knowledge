# 年假实施要点/到期清零的代码

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/939>

【实施参考】

1.  系统的休假模块（hr_holiday）自带假期分配功能，也带有年假自动计算功能（参考[年假自动累加的配置方法](http://www.thinkltd.cn/forum/1/question/932)）。不过实际测试发现年假自动计算功能比较复杂，不太好用。

2.  年假分配建议实施方法是，每年年底，创建一个“常规”的休假分配（hr.leave.allocation），起始日期为次年的1月1日，结束日期为该次年假的到期日期（清零日期），填写次年年假天数，批量查找添加次年年假天数相同的员工到此休假分配（可以根据员工的首次合同日期筛选）。也可以写个**服务器动作一键自动创建次年的年假分配**。

3.  年假到期清零的建议实施方法是，休假分配（hr.leave.allocation）上有到期日期字段（date_from），系统自带一个年假计算的计划任务“应计休假: 更新休假次数”。可以在“应计休假: 更新休假次数”中添加下述代码，将到期了的“休假分配”，剩余假期清零。

![[1-939-900697df.png]]

model._update_accrual()

today = datetime.datetime.now().date()

allocation_ids = model.search([('state', '=', 'validate'), ('date_to', '!=', False), ('date_to', '<', today)])

#raise Warning("已过期的假期分配：%s" % allocation_ids)

```python
for allocation in allocation_ids:

    number_of_days = min(allocation.number_of_days, allocation.leaves_taken or 0.0001)

    allocation.write({"number_of_days": number_of_days, 'active': False})

    allocation._message_log(body="年假到期自动清零！")
```
