# 中国各大银行网银流水接口调查

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:肖相扶 | 2025-08-29
> <http://www.thinkltd.cn/forum/1/4064>

【业务背景】

1.  Odoo企业版内置了欧美各大银行的银行对账单接口，可以直接抓取银行收付款流水，作为系统的银行流水对账单。
2.  但中国各大银行没有接口，通常的做法是，从网银上下载收付流水到Excel，再导入到Odoo中作为银行对账单，参考 [工商银行网银流水Excel导入Odoo银行日记账](http://www.thinkltd.cn/forum/1/excelodoo-4036) 。
3.  客户需求场景是，能不能直连网银自动抓取流水？初步调查，中国各个银行没有统一接口，需要针对每个银行开发接口，银行可能还要签订安全保证合同，以及收取接口费用。本帖子调查中国各家银行的对接条件、费用、技术资料。

【DeepSeek调查结果】

1.  工商银行API接口：工商银行是中国最大的商业银行之一，其API接口在可靠性、易用性和功能性方面表现优秀。提供了丰富的功能，如查询余额、转账、缴费、信用卡申请等。同时，工商银行还提供了完善的开发文档和社区支持，帮助开发者快速上手。
2.   建设银行API接口：建设银行的API接口在易用性和功能性方面表现出色。提供了多种服务，如个人银行业务、企业银行业务和信用卡业务等。此外，建设银行的API接口支持多种数据格式和加密算法，保障了数据的安全性。
3.  招商银行API接口：招商银行的API接口在易用性和安全性方面表现较好。招商银行的开发文档非常详细，包括快速入门、API文档和代码示例等，方便开发者使用。此外，招商银行还提供了多种支付和缴费方式，为开发者提供了更多的选择。

【业务调查结果】

1.  招商银行：招商银行有OpenAPI，有对接的技术资料、接口示例、沙箱测试环境。正式对接需要签订接口协议，有些接口可能需要收费，协议参考 [服务协议-请登录](https://openapi.cmbchina.com/serviceAgreement) 。技术参考1 [调用招商银行接口（手把手教程，附调用接口工具类）-CSDN博客](https://blog.csdn.net/studio_1/article/details/125716174) ，技术参考2 [java对接招商银行_mob649e815b5994的技术博客_51CTO博客](https://blog.51cto.com/u_16175462/13021414)

## 补充/答案 1

工商银行：招商银行有较友好的API文档，部分接口免费或低成本，有对接的技术资料、接口示例、沙箱测试环境。正式对接需要了解中国工商银行工行云平台 用户须知，须知，参考[**工行|开放平台**](https://open.icbc.com.cn/icbc/apip/docs_rules_dtl.html?doc_id=DOC_000055)。      工行api文档：[**工行|开放平台**](https://open.icbc.com.cn/icbc/apip/api_list.html) 技术参考1 ：[**https://blog.51cto.com/u_16213408/13079477**](https://blog.51cto.com/u_16213408/13079477) 技术参考2：[**https://blog.51cto.com/u_16099209/10005197**](https://blog.51cto.com/u_16099209/10005197)

建设银行：建设银行支持 API 接口对接，开发者手册参考[**帮助中心**](https://open.ccb.cn/devportal/onlineBook)(注意：部分功能可能仅对受邀企业或已开户客户开放，需登录企业网银或通过客户经理获取链接与权限.) 正式对接需要的相关协议请联系当地开户行。技术参考1：[**JAva对接建设银行_mob64ca12d9b014的技术博客_51CTO博客**](https://blog.51cto.com/u_16213338/7455683) 技术参考2：[**中国建设银行网上支付接口以及自动对账_银行支付接口-CSDN博客**](https://blog.csdn.net/bosschen/article/details/84009818?ops_request_misc=%7B%22request%5Fid%22%3A%22e17b744ca653b2602089c52ad80422a3%22%2C%22scm%22%3A%2220140713.130102334..%22%7D&amp;request_id=e17b744ca653b2602089c52ad80422a3&amp;biz_id=0&amp;utm_medium=distribute.pc_search_result.none-task-blog-2~all~sobaiduend~default-2-84009818-null-null.142)

农业银行：我行接口的认证方式有两种:基于标准的OAuth2.0认证方式和基于PKI体系的认证方式，快E通接口基于OAuth2.0认证，其他接口都是通过PKI双向签名认证。 正式对接前需要了解中国农业银行开放银行平台用户须知，仅供参考[**中国农业银行开放银行**](https://openbank.abchina.com/Portal/service/userNotice) ，[**中国农业银行开放银行**](https://openbank.abchina.com/Portal/service/guide) 正式对接时签署的相关协议请联系当地开户行。技术参考1：[**java 农业银行支付api_mob649e8163f390的技术博客_51CTO博客**](https://blog.51cto.com/u_16175498/9483195) 技术参考2：[**农行Java接口 账单查询接口_mob649e8168b406的技术博客_51CTO博客**](https://blog.51cto.com/u_16175517/12400739)

中国银行：中国银行并未像某些互联网银行那样完全公开所有 API 文档供个人自由申请使用，大多数 API 是面向企业客户、金融机构或合作伙伴，需要签约、资质审核与报备。 中国银行有对接的技术资料、接口示例、沙箱测试环境，详情请参考[**开发者门户**](https://www.bankofchina.com/ebanking/bocnet_login/201903/t20190307_14902230.html?keywords=%E5%BC%80%E5%8F%91%E8%80%85)。正式对接需要签订接口协议，参考[**中国银行股份有限公司开放银行客户授权协议(对公金融服务)**](https://www.bankofchina.com/ebanking/service/cs1/202207/t20220711_21411224.html?keywords=api)。接口文档及示例请参考：[**中国银行（银企）接口文档及示例**](https://vip.kingdee.com/article/620558262923922432?productLineId=40&amp;lang=zh-CN&amp;islogin=true,true&amp;global=1)
