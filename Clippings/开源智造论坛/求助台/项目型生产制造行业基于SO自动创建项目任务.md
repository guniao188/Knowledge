# 项目型生产制造行业基于SO自动创建项目任务

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/so-802>

【业务背景】

1.  项目型制生产造行业，每一台设备都是定制生产的，且生产周期较长。接到客户订单，订单设备生产涉及图纸设计、工艺设计、进口件采购、生产、采购、仓库、财务等一系列工作。

2.  为了协调各个生产环节和生产任务，通常由项目部负责订单协调。订单成交后，项目部需要协调的任务包括：设计部设计图纸，工艺部门确认工艺，采购部门提前采购周期长的部件（如进口件）。生产过程中，如果发生变更（客户需求变更、技术变更、生产工艺变更，等等各种变更情况），协调变更处理。

3.  在Odoo中，如果是服务型产品，可以在产品档案上配置“项目模板”，销售订单确认时候，系统自动复制项目模板，创建一个以销售订单单号命名的新项目，每一个销售明细行，系统自动创建一个项目任务。创建项目，创建任务的代码参见：OSCGODOO14\source\addons\sale_project\models\sale_order.py   方法 def _timesheet_service_generation(self):
