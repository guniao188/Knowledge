# 安全证书的参考和下载以及后台布署参考

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:符赛红 | 2023-05-04
> <http://www.thinkltd.cn/forum/1/927>

如果客户要上的应用中，会涉及到网站电商或者国外用户访问等，建议可以增加安全机制，即加载ssl安全证书，通过加了安全证书的https来访问，当然也需要有域名。

后台nginx进行设定和绑定，需要ssl证书下载nginx版本。

下载免费证书可以从这里获取：

https://certbot.eff.org/lets-encrypt/ubuntufocal-nginx

但通常免费证书的有效期较短，而付费的证书可以在云服务器云平台上购买，一般有效期也是一年，需要定期进行更换。

更换证书视频参考链接：(参考客户：vital付费版证书的更换，依据购买的有效期长短决定，一般是一年）

链接：https://pan.baidu.com/s/14TPFNsxeX3t35aOyW_i95A
提取码：2b4k

手动续订SSL证书效期操作方法：（参考客户：聚复免费版安全证书，即需要知道nginx的配置及启动命令即可续订成功，每3个月就会要更新一次）

手动续订证书 命令运行3个命令
1. 停止nginx sudo systemctl stop nginx.service
2. 续订证书 "/root/.acme.sh"/acme.sh --cron --home "/root/.acme.sh"
3. 启动nginx sudo systemctl restart nginx.service

另外nginx的配置参考：（suto的ssl证书示例）

##　nginx配置文件 odoo.suto-itec.com.conf

```shell
upstream odoo-suto {
     server 127.0.0.1:8869;

upstream odoochat-suto {
     server 127.0.0.1:8869; # 未开启多进程使用

# 设置HTTP请求自动跳转HTTPS
server {
```python
     listen      80;
     server_name  odoo.suto-itec.com;
     rewrite ^(.*) https://$host$1;
}
```

# HTTPS
server {
     listen 443 ssl;
     server_name odoo.suto-itec.com;

     # Nginx upload size
     client_max_body_size 2048m;
     # Add Headers for odoo proxy mode
```python
     proxy_set_header Host $host;
     proxy_set_header X-Real-IP $remote_addr;
     proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
     proxy_set_header X-Forwarded-Proto $scheme;
     underscores_in_headers on;
```

     #error_page 497  301 302  https://odoo.suto-itec.com$request_uri;
     #error_page 403 https://odoo.suto-itec.com$request_uri;

     # import timeout
```python
     proxy_connect_timeout 600;
     proxy_send_timeout 600;
     proxy_read_timeout 600;
     send_timeout 600;

     ssl on;
     ssl_certificate /etc/nginx/cert/7601402_odoo.suto-itec.com.pem;
     ssl_certificate_key /etc/nginx/cert/7601402_odoo.suto-itec.com.key;
     ssl_session_timeout 5m;
     ssl_ciphers ECDHE-RSA-AES128-GCM-SHA256:ECDHE:ECDH:AES:HIGH:!NULL:!aNULL:!MD5:!ADH:!RC4;
     ssl_protocols TLSv1 TLSv1.1 TLSv1.2;
     ssl_prefer_server_ciphers on;
```

     # log

     error_log /var/log/nginx/odoo-suto.error.log;

```python
