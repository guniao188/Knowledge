# 存档按钮设置权限

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:薄文雅 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/824>

在产品模板中，给”存档“按钮设定权限，只有指定权限组的用户可以存档产品

增加一个自动动作：

```python
for prt in records:
  if prt.active==False:
    if not env.user.has_group('product.archive_product'):
      raise Warning("You can't archive product!")
```

![[1-824-e90e6f12.png]]

## 补充/答案 1

需要事先配置好这个自定义权限组product.archive_product

## 补充/答案 2

如果不想自定义权限组，客户要求统一给到管理员权限用户，用于产品的存档（archive状态）管理的话，可以这样写：

```python
for prt in records:
  if prt.active==False:
    if not env.user.has_group('base.group_system'):

      raise Warning(_("You can't archive product!"))
```

为什么加_这个，是因为这个可以更好的兼容后期Odoo版本的多语言翻译问题！如果中文就不用里面在包含括号_了！

## 补充/答案 3

15版本不生效，会直接报错 server error，没有其他信息

检查日志后发现，日志报错

Warning is a deprecated alias to UserError

即Warning是一个不推荐的别名

把最后一句raise Warning 改成 raise UserError即可
