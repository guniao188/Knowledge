# 批次序号如何实现四位码却有上百万的号可以使用而不重复？

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:符赛红 | 2022-12-15
> <http://www.thinkltd.cn/forum/1/566>

业务背景：批次的应用，为了更好的追溯，往往需要与产品标识挂勾，当产品较小，而批次号码太长，会很难印到产品上，如果批次号码位数太少，则又容易出现批次名字重复项，就失去了追溯的意义。

应用实例及实现方案：

可以启用0~9的数字+A到Z的字母来做，比如四位数的码，就可以实现有36*36*36*36相乘的批次号可供使用，重复的概率是极低的

示例：

0001，……，0009，000A，……，000Z等等

肖总给出的技术实现方案：

解决方法是将 10 进制数转换为 36进制数。 例如Odoo序列号生成的 批次是  000100，这是十进制数。变成36进制数是 ：2S

10进制到36进制的转换代码（参考）

```python
def n_36(n):
    if n < 36:
        return int(n) < 10 and chr(ord('0') + int(n)) or chr(ord('A') + int(n) - 10)
    else:
        return "%s%s" % (n_36(int(n/36)), n_36(int(n%36)))
```
