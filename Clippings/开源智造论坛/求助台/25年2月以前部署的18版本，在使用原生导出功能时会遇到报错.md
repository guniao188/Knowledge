# 25年2月以前部署的18版本，在使用原生导出功能时会遇到报错

> [!info] 来源
> 开源智造论坛 · 求助台 | 作者:葛忠彪 | 2026-07-30
> <http://www.thinkltd.cn/forum/1/25218-4105>

以MO为例，重现方式为：

1.先搜索MO

2.全选

3.点击操作-导出

4.弹窗里点击 产品 这个字段（或者其他many2one类型字段）

报错  ValueError: Invalid field product.product.state in leaf ('state', 'in', ('draft','done'))

 问题根源在于，系统把当前界面的domain，也传递给了弹窗里选中的这个字段的模型去搜索，如果此模型里没有这个字段则报错

官方也有对应帖子说明

[https://mergebot.odoo.com/odoo/odoo/pull/193567](https://mergebot.odoo.com/odoo/odoo/pull/193567)

如果不打算全量更新模块的话，可以参考以下方法

进入源码 /extra/opt/odoo/odoo18/odoo-server/addons/web/static/src/views/list/list_controller.js

下图位置 注释

```python
           let domain = this.model.root.domain;
       加入
         let domain = parentParams ? [] : this.model.root.domain;
```
