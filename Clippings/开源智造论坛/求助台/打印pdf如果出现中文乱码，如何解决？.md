# 打印pdf如果出现中文乱码，如何解决？

打印pdf如果出现中文乱码，如何解决？

![[1-pdf-706-57d1ca15.png]]

答：这是因为缺少安装中文字体的原因，后台安装一下即可。

sudo apt-get install fonts-wqy-microhei
