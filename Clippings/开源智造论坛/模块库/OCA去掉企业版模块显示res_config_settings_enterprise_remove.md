# OCA去掉企业版模块显示res_config_settings_enterprise_remove

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/2/ocares-config-settings-enterprise-remove-2793>

模块链接：

This module removes enterprise-only features from all settings views. Note that it does not remove the possibility to install Enterprise modules. If necessary, all Enterprise Edition code is still available and can be manually installed via the Apps menu.
