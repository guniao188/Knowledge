# 带参数SQL语句抽取数据直接导出到Excel模块sql_export

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/2/sqlexcelsql-export-3485>

模块链接：[OCA/server-tools: Tools for Odoo Administrators to improve some technical features on Odoo. (github.com)](https://github.com/OCA/server-tools)

相应模块：sql_request_abstract，sql_export，sql_export_excel

【模块功能】

1.  配置SQL查询语句，及查询参数，查询权限。而后用户可以在界面上输入参数，查询数据，查询结果直接导出到csv或者Excel

2.  还可以预先配置模板Excel文件，模板文件可以预先配置好各种公式、图表，查询结果直接抽取到该模板文件作为公式、图表的源数据。
