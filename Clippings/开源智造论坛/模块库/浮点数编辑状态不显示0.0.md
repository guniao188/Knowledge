# 浮点数编辑状态不显示0.0

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/2/0-0-3545>

模块位置：OSCG_SVN\odoo_ecommerce\14.0SRC\web_not_display_zero

【模块功能】

1.  Odoo现有功能是，Float类型的字段，默认值是0.0，编辑时候，总是要先删除0.0，再录入。尤其在手机上操作时候，如手机上填写报销单，删除0.0的操作非常不便。

2.  本模块改成，XML字段定义的options增加“not_dispaly_zero”的配置项，如果配置为True，则Float字段，编辑时候不显示0.0。
