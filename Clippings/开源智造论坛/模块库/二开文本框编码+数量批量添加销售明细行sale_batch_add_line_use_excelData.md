# 二开文本框编码+数量批量添加销售明细行sale_batch_add_line_use_excelData

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:施叶寒 | 2022-12-15
> <http://www.thinkltd.cn/forum/2/sale-batch-add-line-use-exceldata-3109>

![[2-sale-batch-add-line-use-exceldata-3109-0306cd07.png]]

模块链接：odoo_ecommerce/12.0SRC/sale_batch_add_line_use_excelData

【业务背景】

1.  有一类业务中，业务员向客户推送产品列表（如Excel格式，列表中含有产品编码、品名、价格等信息），客户勾选需要的产品，填写需求数量，形成Excel文件。

2.  业务员拿到客人的需求文件（Excel），希望可以快速录入系统形成SO文档。

3.  本模块提供的解决办法是，选择Excel中的 产品编码(料号)、数量、单价、品名(说明)几列，复制粘贴到文本框，确认后，系统解析复制过来的文本，添加到SO的产品明细行。Excel复制到文本框的文本，列与列之间以tab键间隔。文本数据示例如下：

产品1 数量1 说明1 产品2 数量2 说明2

当销售业务比较多，每天几百张单据，每张单据可能要有几十条明细行，为了提高手工录单的效率，我们使用该插件复制粘贴批量生成明细行。

【模块功能】

1.  SO上增加按钮“批量添加明细行”，点击按钮，弹出文本框，粘贴 “产品    数量    说明”几列客户需求数据，确认后，系统解析文本，自动添加到SO明细行；

2.  文本框中，列与列之间以tab键间隔，每列文字两端如果有空格，系统会自动去除空格；如果不是tab键间隔，系统报错，不予导入。如果某列数据中存在tab字符则系统可能会解析错误。因此导入之前请确保数据中不含tab键。

3.  料号列，系统自动精确匹配 产品编码、品名、条码三个字段，匹配上，则添加该产品

4.  确认时候，系统首先检查是否所有料号都存在，如果发现有不存在的，系统提示有 “料号不存在”，并列示不存在的料号，报错，不予导入。如果存在多个匹配的产品，系统也报错，不予导入。

5.  说明列，系统自动添加到SO明细行的说明列

6.  数量和价格列，不得带千分符。如果有千分符，请在Excel中去除千分符再拷贝过来。如果有千分符，系统解析数据会报错，导入失败。

【使用方法】

1。 安装sale_batch_add_line_use_excelData模块；

2。创建一张销售单；

3。点击 批量增加明细行 按钮；

4。打开excel，根据提示，按字段顺序，复制粘贴指定单元格的若干列数据。

提供 替换、增加 两种选项；可以使用空数据替换，实现批量删除明细行效果

测试方法：需要一个加载demo数据的数据库，使用模块中名为demo.xlsx的excel，赋值粘贴第2-4行数据进行测试（去表头）。
