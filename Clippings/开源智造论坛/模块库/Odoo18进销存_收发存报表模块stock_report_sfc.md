# Odoo18进销存/收发存报表模块stock_report_sfc

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:肖相扶 | 2025-01-08
> <http://www.thinkltd.cn/forum/2/odoo18-stock-report-sfc-4024>

模块链接：OSCG_Git\18.0\extra-addons\stock_report_sfc

【模块功能】

1.  相比之前的版本（[Odoo14、15、16、18新版收发存报表stock_report_sfc](http://www.thinkltd.cn/forum/2/odoo14151618stock-report-sfc-3531)），本版本做了较大改进。
2.  新增菜单“库存 --> 报表 --> 收发存报表”、“库存 --> 配置 --> 收发存报表”。
3.  库存移动（stock.move）上增加收发存项目字段。增加收发存项目模型，并通过服务器动作自动设置收发存项目。
4.  预置了常见的收发存项目，如：采购入库、销售发货、生产领料、生产入库、销售退货，等等。
5.  预置的自动设置收发存项目的服务器动作的逻辑如下：
6.  # 采购入库 in_purchase：源库位类型为供应商，目标库位类型为内部
    # 生产入库 in_production：源库位类型为生产，目标库位类型为内部
    # 销售退货 in_sale：源库位为类型为客户，目标库位类型为内部
    # 盘盈入库 in_inventory：源库位为类型为盘点，目标库位类型为内部
    # 其他入库 in_other：源库位为类型不为内部，目标库位类型为内部
    #
    # 销售出库 out_sale：源库位类型为内部，目标库位类型为客户
    # 生产领料 out_production：源库位类型为内部，目标库位类型为生产
    # 采购退货 out_purchase：源库位类型为内部，目标库位类型为供应商
    # 盘亏出库 out_inventory：源库位类型为内部，目标库位类型为盘点
    # 其他出库 out_other：源库位类型为内部，目标库位类型不为内部

    # 库间调拨 internal：源库位类型为内部，目标库位类型为内部
7.  收发存报表的取数逻辑如下：
8.  系统从库存移动(stock.move)上分库位获取期初数量、期间入库数量、期间出库数量、期末数量。期间入库和期间出库，按库存移动上的收发存项目细分成如：采购入库、销售退货入库、盘盈入库、生产入库等等，期间出库细分为销售出库、采购退货出库、生产领料出库等等。
```python
    系统从库存计价(stock.valuation.layer)上获取全公司(不分库位)的期初金额、数量，期间入库数量、金额、期间出库数量、金额，期末数量、金额，并计算期初单价、期间入库单价、期间出库单价、期末单价。
    库存计价上期间入库、期间出库的判断方法是，数量大于等于零的都视作期间入库，小于零的视作期间出库。数量等于零的库存计价，来源于到岸成本分摊，以及采购发票价格差异的分摊。
    系统通过期初金额 + 期间入库金额 - 期末金额倒算期间出库金额。如此方式，确保期初金额、期间入库金额、期间出库金额、期末金额是平衡的。
    各类型的数量，乘以相应单价，得到相应类型的金额。如期初金额、采购入库金额、销售出库金额，等等。
```
