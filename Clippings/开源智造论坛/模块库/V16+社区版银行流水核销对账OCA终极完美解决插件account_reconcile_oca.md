# Account Reconcile Oca

 [](http://www.gnu.org/licenses/agpl-3.0-standalone.html) [](https://github.com/OCA/account-reconcile/tree/16.0/account_reconcile_oca) [](https://translation.odoo-community.org/projects/account-reconcile-16-0/account-reconcile-16-0-account_reconcile_oca) [](https://runbot.odoo-community.org/runbot/98/16.0)

## [](https://github.com/OCA/account-reconcile/tree/16.0/account_reconcile_oca#usage)[Usage](https://github.com/OCA/account-reconcile/tree/16.0/account_reconcile_oca#id1)

### [](https://github.com/OCA/account-reconcile/tree/16.0/account_reconcile_oca#bank-reconcile)[Bank reconcile](https://github.com/OCA/account-reconcile/tree/16.0/account_reconcile_oca#id2)

Access Invoicing / Dashboard with a user with Full Acounting capabilities. Select reconcile on the journal of your choice.

### [](https://github.com/OCA/account-reconcile/tree/16.0/account_reconcile_oca#account-reconcile)[Account reconcile](https://github.com/OCA/account-reconcile/tree/16.0/account_reconcile_oca#id3)

Access Invoicing / Accounting / Actions / Reconcile All the possible reconcile options will show and you will be able to reconcile properly. You can access the same widget from accounts and Partners.
