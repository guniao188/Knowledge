# OCA价格表打印product_pricelist_direct_print

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:肖相扶 | 2022-12-15

模块链接：

## [Configuration](https://github.com/OCA/product-attribute/tree/11.0/product_pricelist_direct_print#id1)

To configure this module, you need to:

1.  Go to *Apps* and install *Sales Management*
2.  Go to *Sales > Configuration > Settings*
3.  Scroll to *Pricing*
4.  Set *Multiple Sales Prices per Product* on an either *Multiple prices per product* or *Prices computed from formulas*

##

## [Usage](https://github.com/OCA/product-attribute/tree/11.0/product_pricelist_direct_print#id2)

To use this module, you have several options:

1.  Go to *Sales > Catalog > Print Price List*

2.  Go to *Sales > Catalog > Products*
    - Select products in list view
    - Press *Print > Price List*

3.  Go to *Sales > Catalog > Product Variants*
    - Select products in list view
    - Press *Print > Price List*

4.  Go to *Sales > Orders > Customers**
    - Select customers in list view
    - Press *Action > Send customer pricelist by EMail*
