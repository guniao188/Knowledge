# OCA快速切换用户easy_switch_user

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:肖相扶 | 2022-12-15

模块链接：

#### **模块后菜单不见了，打开报错**

This module lets administrators and developers quickly change user to test e.g. access rights.

### Usage

To use this module, you need to:

1.  Click on the caret in the system tray
2.  Select the user you want to switch to
3.  Login (only required once)
