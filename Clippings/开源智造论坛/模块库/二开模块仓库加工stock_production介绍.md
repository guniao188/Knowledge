# 二开模块仓库加工stock_production介绍

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/2/stock-production-2481>

模块存放位置： OSCG_SVN\odoo_ecommerce\12.0SRC\stock_production
13版本模块存放位置：OSCG_SVN\odoo_ecommerce\13.0SRC\stock_production
经测试，Odoo14可以正常安装

【20220324新增15.0版本】位置：OSCG_SVN\odoo_ecommerce\15.0SRC\仓库加工

**l  应用场景**

1.  1)     仓库加工：例如将整条三文鱼切成鱼头、鱼尾、鱼身，将散装苹果分成不同等级装盒销售

2.  2)     外协加工：将钢卷切成钢条，铝材做表面耐腐蚀处理，整根牛排切成片状牛排

**l  应用特点**

1.  1)     下单时候是按原料数量下单，例如，“今天计划完成200公斤苹果的分装”

2.  2)     下单时候不知道有哪些成品，有多少成品。例如，200公斤可以分出哪些等级，每个等级多少盒，下单时候并不知道

3.  3)     原料出库是一次性的，成品入库可能是多次入库。例如，苹果分装，每完成一批，电商销售可能马上就会拿去发货，而不会等该批加工全部完成再入库

4.  4)     批次追溯，加工出来的东西是哪个原料批次，有追溯要求

5.  5)     加工费用，如果是外协加工的情况，需要给外协厂下加工采购单，支付加工费用

6.  6)     成本核算，加工完成，需要将原料成本、加工费用核算到成品成本上去

**l  解决方案**

1.  1)     Odoo MRP的MO基本原理是，下单时候确定成品需求量，根据BoM计算原料需求量。下单后，不能随意删除、修改原料，也不能随意删除、添加成品。

2.  2)     此类加工，下单时候，不知道成品种类和成品数量，成品和原料之间没有准确的BoM关系。

3.  3)     此类加工，通常是根据原料数量下单，例如，今天要分装完200公斤苹果，又如，请帮我们分切100箱牛排。

4.  4)     本模块新开发加工表单，该表单上可以随意添加、删除、编辑原料行，可以按批次、Package指定原料；可以随意添加、删除、编辑成品行。

5.  5)     加工单的原料行自动产生原料出库Picking，成品行自动产生成品入库Picking。

6.  6)     成品单上有原料批次、成品批次号，有报废数量，可以实现批次追溯，报废数量追溯。

7.  7)     （外协加工的情况）可以基于原料行自动创建供应商账单，可以创建预付款的供应商账单。

8.  8)     成本核算：加工单有“实时(售价加权平均)”、“实时(数量平均)”、“月末”成本核算三种。实时核算的话，加工单结单时候，系统自动创建成品入库单，并自动完成入库，完成成本结转。

9.  9)     月末核算的话，允许多次成品入库，完工结单时候，系统不会自动结转原料成本，而是月末通过另外的方式结转（如全月加权平均成本法）。

10. 10)   系统默认的成本结转算法是售价加权平均，汇总原料成本（Stock Move的Value），及费用账单未税金额，按成品销售单价及成品数量加权平均计算成品成本价

11.

- l  供应商：外协加工的情况，填写外协商

- l  原料出库类型：系统创建原料出库（从实体库位到虚拟的生产库位）的领料单的Picking Type

- l  成品入库类型：系统创建成品入库（从虚拟的生产库位到实体库位）的入库单的Picking Type

- l  加工类型：自定义的加工类型

- l  成本方式：原料成本和费用到成品成本的结转方式，有实时和月末两种方式。实时的话，完工结单时候系统自动创建成品入库单、自动验证成品入库单、自动完成原料及加工费用到成品成本的结转。月末的话，允许多次入库（多次创建成品入库单），完工结单时候，系统不会自动结转成本，一般是月末通过其他方式结转成本（如全月一次加权平均成本计算）。

- l  原料：手工填写的原料消耗明细，系统据此自动创建领料的Stock Picking

- l  成品：手工填写的成品入库明细，系统据此自动创建入库的Stock Picking

-

- l  加工费用：点击创建加工费用的供应商账单（Invoice），可以创建预付款账单

- l  原料出库：点击创建领料单Stock Picking，仓库发料验证。可以多次点击创建多个发料单

- l  成品入库：点击创建成品入库单Stock Picking，仓库入库验证。“月末”成本方式时候，可以多次点击创建多个入库单。“实时”成本方式时候，此按钮不可以见，而是点击“订单完成”时候，系统自动创建入库单，自动完成入库验证，自动结转原料成本和费用到成品成本。

- l  费用账单：点击跳转到关联的供应商账单

- l  原料库单：点击跳转到关联的原料出库单

- l  成品库单：点击跳转到关联的成品入库单

-

## 补充/答案 2

【仓库加工成本结转】

**案例分析：**

- l  原料：Ham 3件，成本价7.92，法式奶油蛋糕 2件，成本价6.88

- l  加工费用（费用账单）：30元

- l  成品：牛奶2件，售价 8元，冰淇淋1件，售价100元

-

l  订单完成时候，系统按成品售价加权平均（售价越高，成本分摊越多）计算成品成本价格：

1.  1)     牛奶入库成本价格 = 8 * ( 3 * 7.92 + 2 * 6.88 + 30) / ( 2 * 8 + 1 * 100 ) = 4.66

2.  2)     冰淇淋入库成本价格 = 100 * ( 3 * 7.92 + 2 * 6.88 + 30) / ( 2 * 8 + 1 * 100 ) = 58.21

3.  3)     该成本同时反应在：加工单的成品明细，成品入库的存货变动明细，成品入库的存货会计凭证

4.

l  实时（数量平均）成本核算的话，系统只按数量平均，不考虑不同成品不同售价。即不管什么售价，都分摊一样多的成本。

l  **注意事项：**

1.  1)     选择“实时”成本方式的话，成品的产品分类的成本方法必须设置为“移动加权平均”或“先进先出”，不可以设置为“标准价法”及“全月加权平均法”；

2.  2)     虚拟库位/生产 的出库、入库科目要设置为“生产成本”；

3.  3)     目前系统自动产生的加工会计凭证，有原料消耗、有成品入库的会计凭证，但缺乏加工费用的会计凭证，需要另外手工录入该凭证。

借   生产成本，贷 制造费用
