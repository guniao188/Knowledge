# Odoo 标准群发营销邮件功能模块mass_mailing

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/2/odoo-mass-mailing-3153>

###   邮件营销

![[2-odoo-mass-mailing-3153-955f4a6f.png]]

 l  **1 Email无法发送**：发送失败的邮件数量，点击显示该部分邮件列表

l  **3发出去的邮件**：成功发出去的邮件数量，点击显示该部分邮件列表

l  **已接收**：成功发送出去了，且没有被弹回的邮件占总邮件数的百分比，点击显示该部分邮件列表

l  **已开启**：收件人打开过的邮件占总邮件数的百分比，点击显示该部分邮件列表。系统判断是否开启过的方法是：系统在邮件中增加了一个非明文显示的链接：”http://Odoo服务器/mail/track/%(mail_id)s/blank.gif ” ，收件人打开邮件时候，该链接连到服务器，服务器记录 mail_id，从而知道收件人打开过邮件。

l  **已回复**：收件人回复了的邮件占总邮件数的百分比，点击显示该部分邮件列表

l  **点击**：收件人点击过邮件中链接的数量占总邮件数的百分比，点击显示该部分邮件列表。系统统计是否点击过的方法是：预先创建一个“跟踪网址”，如下图。将“跟踪网址”设置到邮件正文的链接中。收件人点击链接时候，“跟踪网址”首先记录收件人点击过了，再跳转到真正的网址上去。

** **

![[2-odoo-mass-mailing-3153-12e6a370.png]]

 ****

 l  **被退回**：被收件方邮件服务器“弹回bounced”的邮件百分比

l  **主题**：邮件营销的主题

l  **收件人**：有“联系人”、“线索/商机”、“销售订单”、“邮件列表”四个选项。

n  **联系人**：系统自动获取Partner，从Partner上获取邮箱。代码编辑器中填写联系人的筛选条件

n  **线索/商机**：系统自动获取线索/商机，从线索/商机上获取邮箱。代码编辑器中填写线索/商机的筛选条件

n  **销售订单**：系统自动获取销售订单，从销售订单上获取邮箱。代码编辑器中填写销售订单的筛选条件

n  **邮件列表**：预定义还邮件列表，系统从选定的邮件列表上获取邮箱。

![[2-odoo-mass-mailing-3153-5075339d.png]]

 l  **邮件内容**：HTML的邮件内容，可以使用 ${object.name} 获取对象上的字段值。

![[2-odoo-mass-mailing-3153-04751dde.png]]

  l  **来自**：群发邮件的发件人邮箱

l  **回复**：收件人回复群发邮件时候，回复到哪里。如果收件人选择的是“线索/商机”、“销售订单”两种情况，可以指定回复到“收件人关注者”，表示回复邮件自动进入到对应表单下面的Message区域。“指定的邮件地址”表示，邮件回复到指定邮箱（如公司sales邮箱）。

l  **邮件服务器**：群发邮件的发件服务器

l  **在将来计划**：本营销邮件计划什么时间发送。系统实际是将邮件放到邮件群发队列，邮件队列是一个计划任务，定期发送。

l  **归档**：默认情况，邮件发出去以后，系统自动从群发队列中删除邮件。如果勾选，则不删除，邮件一直存储在系统中。

###   邮件列表

![[2-odoo-mass-mailing-3153-4e9ac9e2.png]]

 l  **被退回**：该邮箱被“弹回”过，发不了邮件

l  **退出**：该收件人点击过“退出”链接，不想再接收营销邮件

l  **黑名单**：该邮箱被列入黑名单。“弹回”次数太多的邮箱，系统会自动加入黑名单
