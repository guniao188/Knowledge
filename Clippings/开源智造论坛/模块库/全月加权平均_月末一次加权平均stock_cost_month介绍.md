# 全月加权平均/月末一次加权平均stock_cost_month介绍

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:肖相扶 | 2025-01-06
> <http://www.thinkltd.cn/forum/2/stock-cost-month-2465>

【注意】Odoo18请参考新模块，有了较大改善： [Odoo18月末一次加权平均成本计价方法stock_costs_month_end](http://www.thinkltd.cn/forum/2/odoo18stock-costs-month-end-4025)

- l  期初：全月一次加权平均成本价格计算的期初，系统默认是上月1日（通常是月初计算上月成本）。

- l  期末：全月一次加权平均成本价格计算的期初，系统默认是上月最后一日。

- l  产品：需要成本计算的产品，手工添加到计算表单。注意，如果是生产型企业，必须先计算原料成本，再计算半成品成本，最后计算成品成本。原料、半成品、成品，必须分三个表单，分三次计算。

- l  期初数量：期初时间点（前一月月末），产品的库存数量

- l  期初单价：期初时间点（前一月月末），产品的成本价格，系统直接取产品的“成本价格”字段。

- l  入库单价：入库单价 = 该产品当月入库总金额 / 该产品当月入库总数量。如果是采购入库，金额取采购单上的去税价格，如果是生产入库，金额算法：取生产单（MO）的原料总成本金额，除以入库的成品数量，得到入库成本单价。其他情况取产品的“成本价格”字段

- l  分摊单价：费用明细行中的费用，分摊到该月入库的所有产品上，本产品分摊到的成本单价。常见的费用类型包括：采购入库的运费，生产入库的人工费、水电费、折旧费等，进口商品的关税、清关费、保险费等。

- l  本月单价：全月加权平均成本法计算的产品本月成本价格。本月单价 = [ 期初数量 * 期初单价 + (入库单价+ 分摊单价) * 期间入库数量 ] / [ 期初数量 + 期间入库数量 ]

- l  期间入库数量：该产品该月的入库总数

- l  期间入库金额：该产品该月的入库总金额，计算公式为：(入库单价+ 分摊单价) * 期间入库数量

- l  期间出库数量：该产品该月的出库总数

- l  期间出库金额：该产品该月的出库总金额，计算公式为：本月单价 * 期间出库数量

- l  期末数量：该产品该月月末数量，计算公式为：期初数量 + 期间入库数量 - 期间出库数量

- l  期末金额：该产品该月月末金额，计算公式为：期末数量* 本月单价

- l  入库明细行：选定产品该月入库的所有明细。系统自动抓取已完成的，且完成日期（date）在计算期间的入库 Stock Move记录。

- l  源单据：哪个单据入库的

- l  数量：取自入库Stock Move的数量

- l  成本价：采购入库的情况，取自采购明细行对应的供应商账单的去税单价，没有供应商账单的，取自采购订单的去税价格，生产入库的情况，生产入库的Stock Move的MO的原料总金额（已领料消耗的部分）/ 成品入库数量，其他情况取自Stock Move的price_unit

-

- l  费用明细行：手工录入的需要分摊到当月存货成本的所有费用

- l  源单据：可以记录费用单的单号（如发票号码）

- l  产品：费用类型，如运费、关税、加工费等服务类产品

- l  单价：费用金额

- l  分摊方法：支持的分摊方法包括，按入库产品数量分摊，按入库产品成本分摊，按入库产品重量分摊，按入库产品体积分摊。默认是“按入库产品成本分摊”，计算公式是：入库单价* 费用总金额/ 入库产品总金额

-

- 出库明细行：选定产品该月所有出库明细。系统自动抓取已完成的，且完成日期（date）在计算期间的出库 Stock Move记录

- 源单据：哪个单据出库的

- 原价：成本计算前出库Stock Move上的出库成本单价price_unit （仅供参考，在全月加权平均成本法情况下，没有实际意义）

- 新价：全月加权平均成本计算后，更新的该月出库成本价格。
