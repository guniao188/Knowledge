# OCA打包到托盘stock_picking_package_preparation

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/2/ocastock-picking-package-preparation-2560>

模块链接：

创建一个包裹准备单，选择多个就绪的Picking放入该准备单，点击按钮，批量入库到同一个包裹（例如托盘）。

This module adds a new document in the Warehouse menu: **Package Preparation**. It works on a selection of pickings and allows to add them all in the same package, then to transfer all the pickings at once.

A possible use case is to put all the selected pickings on a pallet.

## 补充/答案 1

安装模块 stock_picking_package_preparation_line 以后，Package Preparation表单上增加了Prepare Line明细行。
