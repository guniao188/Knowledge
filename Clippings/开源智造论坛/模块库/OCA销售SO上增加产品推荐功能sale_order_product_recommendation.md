# OCA销售SO上增加产品推荐功能sale_order_product_recommendation

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/2/ocasosale-order-product-recommendation-2687>

模块链接：

SO上增加产品推荐按钮，点击按钮，显示该客户最近的销售产品、发货次数、发货数量，本单推荐数量。

This module adds a recommended products wizard to current sale order.

It is based on recent delivered products, and allows the salesman to quickly know the most sold products for current customer, which results in an easy to use hint to improve sale.

To use this module, you need to:

1.  Create a new sale order.
2.  Assign its customer.
3.  Press *Recommended Products* button.
4.  Add products into the opened wizard.
5.  Press *Accept*.
