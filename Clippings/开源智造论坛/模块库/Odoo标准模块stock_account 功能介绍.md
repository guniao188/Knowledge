# Odoo标准模块stock_account 功能介绍

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/2/odoostock-account-2450>

【模块功能】存货价值、入库出库的会计凭证等功能。

- 支持标准价、移动平均、先进先出 三种成本计算方法

- 入库时候在库存移动（Stock Move）上记录存货增加，出库时候在库存移动（Stock Move）上记录存货减少

- 移动平均法情况，采购入库或采购退货时候，计算成本价格，更新产品上的成本价格。先进先出法情况，出库时候用最新出库价格更新产品上的成本价格。

- 如果设置为自动存货会计凭证，则入库、出库时候自动产生会计凭证

本篇模块介绍适用于Odoo 11.0及12.0

## 补充/答案 1

【存货变动明细】案例分析：

1.   新建产品“ [BG3008] 法式巧克力饼干”，期初成本8元，期初库存100个；

2.   销售出库50个；

3.   采购100个，价格9元

1.   第一条库存变动记录：期初盘点，数量（总数）100，期初成本价格8元，库存价值（总值）800元；

2.   第二条库存变动记录：销售订单SO024销售出库（总数）50，出库成本价格（单价）8元，出库总成本（总值）400元；

3.  第三条库存变动记录：采购订单PO00029采购入库（总数）100，入库单价（单价）9元，入库总价格（总值）900；

4.  发生上述业务以后，库存价值余额（余值）1300，库存数量余额（余值）150；

## 补充/答案 2

【成本价格历史及存货分录】

1.   第二条记录：产品“ [BG3008] 法式巧克力饼干”期初成本价格设定 8元；

2.  第一条记录：该产品成本计价方法为移动加权平均法（average），因此采购入库时候，系统自动计算成本价格。PO00029采购入库100个（变更时数量），采购价格9元（变更时价格），入库前库存50个（变更前数量），入库前成本价格8元（变更前价格）。入库后重新计算成本价格 =  (50 * 8 + 100 * 9 ) / ( 50 + 100) = 1300 / 150 = 8.67 元（成本价）。

【存货会计分录】

 最下面两条是库存盘点分录：

  中间两条是销售出库成本结转分录：

n  贷  库存商品            400

 最上面两条是采购入库分录：

## 补充/答案 3

【库存价值报表】

  **手动库存计价：系统基于库存变动Stock Move计算库存价值。**

1.      标准价法：库存价值 = 历史时间点的库存数量 * 历史时间点的成本价格。“历史时间点的成本价格” 从“成本历史价格表(product.price.history)”查得。

2.      移动平均价：同标准价法。

3.      先进先出法：汇总“历史时间点”之前的Stock Move的总值(value)，即得库存价值。入库的Stock Move总值为正数，出库的Stock Move总值为负数。负数出库的Stock Move，总值中包含负数价值，负数冲平时候，总值、余值、余数都会被修正。

4.      全月平均法：同标准价法。

 **自动库存计价：系统基于存货会计凭证计算库存价值。**

1.      标准价法：查询会计分录表（account.move.line），汇总该产品、库存价值科目（库存商品科目），历史时间点之前的会计分录，汇总 其数量（quantity字段），得到库存数量。库存价值 = 库存数量 * 历史时间点的成本价格。“历史时间点的成本价格” 从“成本历史价格表(product.price.history)”查得。

2.      移动平均价：同标准价法。

3.      先进先出法：查询会计分录表（account.move.line），汇总该产品、库存价值科目（库存商品科目），历史时间点之前的会计分录，汇总其科目余额，即得库存价值。

4.      全月平均法：同标准价法。

**库存计价方法（手动、自动）变更：**从库存价值原理看，产品的库存计价方法从自动改为手动，库存价值计算是OK的，但从手动改为自动，需要补全之前的库存移动的会计分录，否则库存价值不正确。

**存货价值报表中，**如果是FIFO的成本计算方法，系统会显示小图标，点击展开“存货变动明细”表。其他成本计算方法，无此小图标。

## 补充/答案 4

【库存价值记录（库存移动）】存货价值记录于“存货变动明细Stock Move”上，该表有总值、余值、余数和库存价值相关字段，如下图：

** 完成数量：存货变动数量，也即入库或出库的实际数量。**

** 单价：存货变动的成本价格，不同成本计算方法，其取值方法不同。**

1.      标准价法：采购入库，其值取自产品上的成本价格。出库，其值取自产品上的成本价格。

2.      移动平均法：采购入库，其值取自采购明细上的去税价格。出库，其值取自产品上的成本价格。

3.      先进先出法：采购入库，其值取自采购明细上的去税价格。出库，系统按先进先出法取得批次成本价格（注意不是price_unit，批次成本价格 = 批次余值 / 批次余数），如果没有负数出库，单价 = FIFO取得的总价值 / 总数量，如果有负数出库，单价 = FIFO取得的最后一个批次的批次成本价格。

4.      全月平均法：采购入库，其值取自产品上的成本价格，但该月全月平均计算后，其值被修改为该月的全月平均价格。出库，其值取自产品上的成本价格，但该月全月平均计算后，其值被修改为该月的全月平均价格。

 **总值：存货变动总价值，入库情况为正数，出库情况为负数。不同成本计算方法，其取值方法不同。**

1.      标准价法：采购入库，其值取自产品上的成本价格 * 入库数量（完成数量）。出库，其值取自产品上的成本价格 * 入库数量（完成数量）。

2.      移动平均法：采购入库，其值取自采购明细上的去税价格 * 入库数量。出库，其值取自产品上的成本价格 * 入库数量。

3.      先进先出法：采购入库，其值取自采购明细上的去税价格 * 入库数量。出库，系统按先进先出法取得批次成本价格（注意不是price_unit，批次成本价格 = 批次余值 / 批次余数），乘以批次锁货数量，得到批次锁货价值。如果没有负数出库，总值 = 批次锁货价值之和，如果有负数出库，总值 = 批次锁货价值之和 + 负数数量 * 最后一个批次成本价格。

4.      全月平均法：采购入库，其值取自产品上的成本价格 * 入库数量（完成数量），但该月全月平均计算后，其值被重算（新价格 * 入库数量）。出库，其值取自产品上的成本价格 * 入库数量（完成数量），但该月全月平均计算后，其值被重算（新价格 * 入库数量）。

 **余值：**入库的情况，其初始值等于总值。出库的情况，如果没有负数出库，其值为0，如果有负数出库，其值为负数部分的价值（负数，其值 = 负数数量 * 最后一个批次成本价格）。

 **余数：**入库的情况，其初始值等于完成数量。出库的情况，如果没有负数出库，其值为0，如果有负数出库，其值为负数出库的数量（负数）。

 **负数冲平：**负数出库的Stock Move（强制出库），当有入库Stock Move时候，系统用入库Stock Move的余值、余数冲销负数Stock Move的余值、余数。

## 补充/答案 5

【基础设置】基础的成本核算相关设置有三处：产品上的成本价格、产品分类上的成本计算方法等、虚拟库位上的会计科目。其中最主要的是产品分类上的设置，如下图：

  **成本：新建产品时候，需要设置此值。此值作用如下：**

1.      新建产品期初库存盘点时候，系统取此值作为初始的存货成本价格；

2.      标准成本法（计划法）时候，系统取此值作为入库或出库的成本价格；

3.      移动加权平均成本法时候，每次入库，系统更新此值，计算公式：新成本价格 = ( 当次入库总金额 + 入库前库存总金额 ) / ( 当次入库数量 + 入库前库存数量 )；

4.      全月加权平均成本法时候，每次全月平均成本计算后，系统更新此值；

5.      先进先出(FIFO)成本法时候，每次出库完毕，系统以当次出库的成本价格更新此值；

6.      此值的更新历史记录在“成本历史价格表(product.price.history)”。

 **成本方法：有标准价、全月平均、移动平均、先进先出 四种成本计算方法；**

1.      标准价：入库时候的存货增加、出库时候的存货减少，都以产品上设定的成本价格作为计价基础。系统任何时候不会自动修改成本价格。

2.      全月平均价：每月计算一次成本价格，计算完毕，自动修改产品上的成本价格，并以此价格作为该月出库成本价格。新成本价格 = ( 该月入库总金额 + 前月库存总金额 ) / ( 该月入库数量 + 前月库存数量 )

3.      移动平均价：每次入库，系统计算一次成本价格，并以此价格作为此后出库的成本价格（直到下一次入库又会再次计算新的成本价格）

4.      先进先出法：系统记录每次的入库价格，出库时候，系统按先进先出原则取得出库成本价格。

 **库存计价：有手动、自动两个选项。**

1.      手动：入库、出库时候，系统不会自动产生该产品的存货变动会计凭证；

2.      自动：入库、出库时候，系统自动产生该产品的存货变动会计凭证；

** ****收入科目：**销售开票时候，应收账款的对方科目，通常是 主营业务收入

**费用科目：**采购开票时候，应付账款的对方科目，通常是 应付暂估

** ****库存进货科目：**入库时候，库存商品的对方科目，采购入库通常是 应付暂估，生产入库通常是 生产成本，盘盈入库通常是 待处理财产损溢

**库存出货科目：**出库时候，库存商品的对方科目，销售出库通常是 主营业务成本，生产领料通常是 生产成本，盘亏出库通常是 待处理财产损溢

** ****库存计价科目：**库存价值科目，流通企业通常是 库存商品，生产企业通常是 库存商品-产成品、库存商品-原材料

** ****库存计价科目（入向）：**入库到此库位时候，库存商品的对方科目，虚拟库位才填此科目，常见情况包括：盘点库位填 待处理财产损溢，生产库位填 生产成本

** ****库存计价科目（出向）：**从此库位出库时候，库存商品的对方科目，虚拟库位才填此科目，常见情况包括：盘点库位填 待处理财产损溢，生产库位填 生产成本
