# Odoo13新增优惠券和促销方案模块sale_coupon

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/2/odoo13sale-coupon-3192>

![[2-odoo13sale-coupon-3192-1e43c0db.png]]

l  **条件**：本优惠券适用的条件，可以是指定的产品，高于指定的购买数量，订单金额高于指定金额

l  **编辑域**：点击录入筛选条件，筛选可以折扣的产品

l  **数量**：订单数量高于此值，才可以享受优惠

l  **最低购买**：订单金额高于此值，才可以享受优惠

l  **有效期**：本规则产生的优惠券的有效天数

l  **奖励**：优惠规则，优惠形式有价格折扣、免费送指定的产品、免费送货三种。

l  **应用折扣**：有百分比和固定金额两种折扣方式。固定金额表示，直接整单减价固定金额。百分比的话，可以指定是整单折扣，还是仅仅最低价的产品折扣。

l  **生成优惠券**：点击按钮，系统弹窗，录入优惠券数量，系统自动创建优惠券

n  **选定客户数**：输入域条件，筛选客户。创建适用于筛选出来的客户的优惠券。

![[2-odoo13sale-coupon-3192-a20d9bef.png]]

l  **销售**：点击，跳转到应用了本规则的优惠券的销售订单列表

l  **优惠券**：点击，跳转到本规则生成的优惠券列表页面

n  **代码**：优惠券的代码，应用优惠券时候，必须输入此代码

n  **到期日期**：优惠券的有效期

n  **对于客户**：该优惠券适用的客户

n  **订单关联**：应用该优惠券的订单

n  **状态**：该优惠券是否有效

## 补充/答案 2

测试发现，奖励选择：免费送指定的产品时，选择的奖励产品，必须和你销售单下单的产品一致，才能有效果。比如，设置指定的免费产品是“酸奶”，销售单上的产品必须也是酸奶，才会根据促销方案的规则，减去赠送的钱。

当“任意商品满100或者购买面包买10件，送酸奶一瓶”这样的需求，这个功能就实现不了了。所以局限性还是比较大。

## 补充/答案 3

优惠券的应用方法是，产生优惠代码，发送给顾客，顾客消费时候提供优惠代码，享受优惠。促销方案则不需要发放优惠代码，可以直接应用，不需要顾客提供优惠券代码。

促销方案的规则设置基本上和优惠券一样，下面就不同之处予以说明。

l  **促销代码的使用**：选择使用代码，则应用促销时候，需要输入指定的代码

l  **适用于第一**：当本促销方案应用次数超过此处指定的次数时候，不再可用

l  **开始日期、结束日期**：本促销方案的适用时间段。
