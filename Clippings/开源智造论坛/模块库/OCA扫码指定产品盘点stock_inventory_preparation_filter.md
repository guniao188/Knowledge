# OCA扫码指定产品盘点stock_inventory_preparation_filter

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/2/ocastock-inventory-preparation-filter-2891>

模块链接：

盘点单上增加按多个产品分类、多个产品、扫描产品，进行盘点。

Includes more options for making an inventory out of:

- Multiple products.
- Products of a category.
- Multiple lots

It also allows to make an inventory based on scanned products, adding a line with product code and quantity.
