# OCA SO添加发货备注并带到发货单sale_stock_picking_note

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/2/oca-sosale-stock-picking-note-2668>

模块链接：

1.  Place a new sale order with stockable products.
2.  Go to *Other information* tab and set the **Picking Note** you want to.
3.  Confirm the Sale Order and go to the created picking.
4.  The note will be available under the *Additional Info* tab.
5.
