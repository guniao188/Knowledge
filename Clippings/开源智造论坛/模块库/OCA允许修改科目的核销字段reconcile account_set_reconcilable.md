# OCA允许修改科目的核销字段reconcile account_set_reconcilable

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/2/ocareconcile-account-set-reconcilable-2723>

模块链接：

允许修改科目上的核销字段reconcile，修改时候，系统自动重新计算用到该科目的Account Move Line的核销金额。

Allows to set as reconcilable a non reconcilable account that already have journal items.
