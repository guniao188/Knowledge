# MTO路线跑出生产订单后，如果生产订单有欠单，销售订单上的小卡片只能跳转到第一个完成的生产订单上

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:葛忠彪 | 2024-01-17
> <http://www.thinkltd.cn/forum/2/mto-3580>

```python
def action_view_mrp_production(self):

        self.ensure_one()

        mrp_production_ids = self.procurement_group_id.stock_move_ids.created_production_id.procurement_group_id.mrp_production_ids.ids

        action = {

            'res_model': 'mrp.production',

            'type': 'ir.actions.act_window',

        }

        if len(mrp_production_ids) == 1:

            action.update({

                'view_mode': 'form',

                'res_id': mrp_production_ids[0],

            })

        else:

            action.update({

                'name': _("Manufacturing Orders Generated by %s", self.name),

                'domain': [('id', 'in', mrp_production_ids)],

                'view_mode': 'tree,form',

            })

        return action
```
