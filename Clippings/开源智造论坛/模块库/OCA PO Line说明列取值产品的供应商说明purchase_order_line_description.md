# OCA PO Line说明列取值产品的供应商说明purchase_order_line_description

> [!info] 来源
> 开源智造论坛 · 模块库 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/2/oca-po-linepurchase-order-line-description-2628>

模块链接：

## [Configuration](https://github.com/OCA/purchase-workflow/tree/11.0/purchase_order_line_description#id1)

The user has to belong to group_use_product_description_per_po_line. This is possible by checking the related option in the following settings:

- Purchases > Configuration > Settings > Purchase Order > Order lines description.

##

## [Usage](https://github.com/OCA/purchase-workflow/tree/11.0/purchase_order_line_description#id2)

1.  Go to **Setting > Users & Companies > Users** and check you have checked the "Use only product purchase description on order lines" access right.
2.  Add or modify a purchase description to any of your products.
3.  Create a purchase order and add a purchase line with this product and check out that now purchase order line description only contains the description you are created.
