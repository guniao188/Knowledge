# 0 免费开源Odoo MES系统简介

> [!info] 来源
> 开源智造论坛 · 市场库 | 作者:肖相扶 | 2023-03-21
> <http://www.thinkltd.cn/forum/4/0-odoo-mes-3651>

- 智能制造是国家战略，是实体产业升级的突破方向。支撑生产企业智能制造最重要的管理系统是车间执行管理系统（MES）。本文介绍世界排名第一的开源免费Odoo企业管理套件 中，MES系统功能。
- Odoo MES系统是开源免费Odoo企业管理套件中，车间现场管理相关的功能模块合集。Odoo MES接收生产任务单，执行车间计划管理、现场管理、车间质量管理、线边库管理等功能。Odoo MES的生产任务单可以来自Odoo ERP（无缝集成），也可以来自其他ERP软件（接口导入），或者Excel文件批量导入生成任务。

![[4-0-odoo-mes-3651-7cacc078.png]]

- MES系统基于生产任务单，创建生产工单(Manufactory Order, MO)。如果是多层BoM结构的设备，系统除了创建总装MO单，还会创建各个部件生产的子MO单。
- MO单的生产过程如果有多道工序（工艺路线中设置产品的生产工序），系统自动将MO单按工艺路线分拆为工序单(WO, Work Order)。工序间的关系，可以是线性的(前一道工序完工了，才可以开始下一道工序)，也可以是并行的(工序不分前后，可以同时开工)。
- 工序上可以设置多个工步。典型的工步如，插电路板、面板焊接、扫码记录原料批次号、工件拍照、打印标签、质检等。
- 车间调度，车间可以调度MO，也可以调度WO。如安排生产工单什么时候开始、哪个产线/班组负责、要求什么时候完成生产。调度WO的情况，可以安排哪个人、哪个机台、什么时候、负责哪个工序生产。
- 生产绩效：车间调度模块可以查看生产工人或班组工作负荷情况。工作负荷包括工人或班组已分配的工作件数和工作时数，完成的工作件数和工作时数，未完成的工作件数和工作时数。车间调度参考工作负荷分配新的生产任务（生产工单或工序单）。
- 现场记录，车间工作现场，工人打开平板电脑，登录MES系统。系统显示待加工MO单，工人点选加工单开始作业。平板上显示加工工步，不同类型的工步，平板上显示的内容不同。
- - 批次记录工步：“记录原料批次”，平板上显示需要记录批次的原料列表，工人点击选原料，扫码或手工录入该原料批次。平台电脑连接扫码枪。
  - 拍照工步：平板电脑通过IoT Box连接摄像设备，平板上点击“拍照”按钮，系统自动控制摄像设备拍照并采集照片，上传到对应的工序单WO上；
  - 测量工步：平板上显示待测量的参数(及参数允许的误差范围)，工人手持数字化测量设备（如游标卡尺），测量工件数据，系统通过IoT Box自动采集测量结果，并自动判断结果是否合格（是否在误差范围内）；
  - 标签打印工步：平板电脑通过IoT Box连接标签打印机，平板上点击打印按钮，系统自动生成标签文件（PDF）并发送打印机打印。标签文件(PDF)格式可以在系统上在线定制。
  - 合格/不合格工步：通常对应质检步骤，质检员质检完毕，判定工件合格（平板上点击“通过”按钮），或者不合格（平板上点击“不通过”按钮）；
  - 其他工步：可以自定义更多类型的工步，如震动台测试工步，通过IoT Box连接震动台，自动采集震动测试结果数据。IoT Box连接非通用设备的情况，可能需要开发设备对接的驱动程序。驱动程序运行于IoT Box上。
- 移动工位PAD操作：如装车发运工位，系统支持PAD操作，如扫描装车单，填写车牌号、装车拍照等。
- 生产进度：系统可以查询各个MO单的完工状态，也可以查询各个工序单（WO）的完工状态。完工状态可以是状态信息，如未开始、进行中、部分完工、完工，也可以是进度百分比，如计划10台，已完工3台。
- 现场问题反馈：工人在平板电脑上，一键提交现场问题单。典型的现场问题如“设计图纸不正确”、“设备故障”、“原料不合格”等等。可以自定义现场问题反馈单的处理流程，如班组长确认-->质检部确认 --> 设计部确认 --> 物资部确认，等等。也可以自定义问题单，或者其他一些现场单据如质检单的打印格式。
- 返工/维修：如果是返工任务单，系统自动创建返工/维修MO单。返工/维修MO单上，可以更换零部件。
- 生产看板：车间大屏幕显示生产状态信息，如今日总MO单数量、完成数量、未完成数量、不合格数量，班组计件排名，等等。
