# 机加工厂信息化/ERP探讨

> [!info] 来源
> 开源智造论坛 · 市场库 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/4/erp-58>

我们是嘉兴一家规模不大的机械加工厂，几十台机床，百来个工人。我们的业务，接到客户订单，例如客户要加工5000个特种螺丝螺母，评估一下客户要求，成本价格，而后给客户报价。客户认可了，图纸室画图纸，而后交给车间加工。车间加工，典型的作业包括，以某型号六角螺母为例，下料 => 打毛孔 => 车外圆 => 铣六角 => 外协镀锌 => 质检入库 => 发货

我们工厂不大，但我们信息化还算做得比较早的，工厂成立的第二年，基本站稳脚跟，我就开始筹划信息化管理。我们第一代ERP软件用的是SAP B1，大概花了20多万。这个预算，对于我们小厂来说，还是蛮吃力的。第一次上ERP，没经验，不知道怎么搞，前后折腾了差不多一年，总算用起来了。

要说第一代ERP带来了什么好处，最大的改善是，应收账款清楚了。哪家客户，什么时候，哪个订单，什么时候发货的，什么时候该收钱，这个问题，系统一查，很清楚。要说这个ERP有什么不足，那还是比较多的。

最大的问题是，我们生产进度管不起来。订单到了车间，一团黑，做到哪一步了，什么时候可以发货，谁负责的，交期有没问题，完全不知道。客户催得急了，我们催跟单，跟单去车间找。有时候紧急插单，手头单放一边了，过个几天，谁也不知道。某一天，客户催货，才发现这个订单在车间晾了几个月了。

其次是，当初上ERP，瞎折腾了半年多，搞那个BoM，还有各种加工工艺，但实际上，最后都没用。因为，我们几乎每个订单都是客人定制的，每个订单的每个产品，都要新建料号，新建BoM，新建工序路线。这个工作看起来不复杂，但订单多，实际做起来，工作量大，很容易做错。

料号、BoM、工序建好了以后，下生产单，系统自动运算物料缺口，自动产生加工单，这就是所谓的MRP运算。看起来好像ERP可以自动规划生产任务，但实际工作中，由于插单、人员请假等各种问题，同样的工序，有时候启用一个机床，有时候启用5个机床一起加工，碰到订单多的时候，还会一部分自己做，一部分外协。ERP规划的加工单，基本是废物，用不了。

说起来好笑，当初我费了好大的劲才弄明白ERP那套生产逻辑，弄明白以后却发现，ERP公司引以为傲的MRP，其实对我们毫无用处。**ERP对我们这种工厂，到底有没有用，有什么用，怎样才能有用**。第一代ERP上完以后，这个问题时不时在我头脑里出现。每次跑到我们一些大客户那里，尤其是几家规模很大的设备制造公司，我会特意留意他们ERP的使用情况。其中有好几家上的是几千万的SAP R3。

几年琢磨下来，我发现，ERP的那套生产逻辑，对于大厂，还是有用的。第一个用处是，缺料计算，像他们设备公司，一套设备几千个零部件，仓库里面哪些有料，哪些没料。没有ERP，还真算不清楚。第二个用处是，生产计划，他们大公司，计划比较规范，定好了明天生产什么，下周生产什么，基本不会变。因此，ERP里面算出的生产计划，还是可以用的。

我们小工厂没那么好命，大客户一个电话，连夜要插单，哪有什么计划啊。另外，那个缺料计算，我们物料简单，原料就一种，钢管，钢筋，或者钢板，裁切以后，几种机床，一路加工，就是成品。接到订单，物料需求，口算都算得出来，用不着ERP。

想明白这些，有好几年，我认定了ERP对我们没用。中间有一段时间，请了一个软件公司，帮我们定制开发一套软件。也搞了一年多，又花了几十万，开发的软件也没用起来，又打水漂了。

直到去年，在金华一个朋友的工厂里面，他们是铸造厂，也有机加工。基本业务就是，废钢熔成铁水，浇铸成模型，再通过机加工进行打磨、刨铣，完工入库。

我看到他们机加车间，每个工件筐上贴了一个二维码标签，工人加工完一筐，手机扫一下那个二维码，就表示做完了。质检人员，包括首检和巡检，检完了，也是扫一下筐上的二维码，录入质检结果，看上去很高级。

我问朋友怎么做的，他支支吾吾也没说清楚，不过，朋友把他们的软件开发商推荐给我了。是上海的一家公司，用的那个软件叫Odoo，是欧洲的一个ERP软件。非常奇怪的是，那个软件免费，直接可以从网上下载。后来我才知道，那样的软件叫开源软件，就是免费，软件还完全公开，可以自己进一步开发。

上海那家公司就是基于Odoo，为朋友公司开发了一套铸造行业用的ERP，包括车间工人手机扫码的功能。今年2月份，正好疫情期间，没什么事，我联系了上海的那家公司，试用了一下他们给我朋友公司搞的那套ERP。当然，我只感兴趣机加的那部分，前面的铸造部分，我没兴趣。

用下来，感觉很不错，有一种眼前一亮的感觉。这套软件没有走MRP的那套逻辑，例如，接到订单，要生产5000个六角螺母，系统中下一个六角螺母的生产单，以及第一道工序（下料）的任务单。下料完成，产生了20筐工件（一筐大约250个），电脑打印20个二维码标签，帖在工件筐上，每筐一个标签。标签上标明了生产单号、工件种类、数量、编号等。

工件筐在工序间流转，流到某道工序，工人按图纸加工，加工完，手机扫描工件筐标签上的二维码，录入完工数、报废数。系统自动记录加工时间、加工人、加工数量。质检人员也一样，平板电脑扫码标签，录入质检参数、合格/不合格数量。不合格的工件，还可以拍照上传。

![[4-erp-58-48dab5a7.png]]

这个软件设计很巧妙，**一个手机扫码，同时解决了订单进度、质量追溯、工人计件三个问题**。试用还发现，除了这个车间生产管理，Odoo还有很多功能模块，销售、采购、仓库、财务、客户管理等，功能比我们用的SAP B1还多。听顾问公司讲，这个Odoo有几万个功能插件。

软件免费，有朋友的应用先例，试用下来感觉也不错，于是，我们三月份就开始实施Odoo ERP了。进展很快，Odoo顾问公司，开源智造，只用了两个月的时间，帮我们上线了销售、采购、仓库、车间管理，包括车间手机扫码。5月份开始，我们SAP B1基本停用了。
