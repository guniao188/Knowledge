# Odoo订单排产详解

> [!info] 来源
> 开源智造论坛 · 市场库 | 作者:肖相扶 | 2024-07-26
> <http://www.thinkltd.cn/forum/4/odoo-3952>

世界排名第一的免费开源Odoo ERP，如何帮助汽配生产企业优化订单排产，缩短客户交期？
汽车零配件生产企业，缩短客户交期的方法中，优化生产计划是一个重要的方法。生产计划，即排产，面临的问题有哪些呢？首先是订单分解，其次是物料齐套，三是产能计划，四是异常插单。

1.  订单分解，接到客户订单，需要将成品生产单拆解为半成品加工单、成品组装单、物料采购单。不同的单据分属不同车间、产线、部门负责。
2.  物料齐套，接到客户订单，要计算物料需求数量，减去可用的库存数量，缺料部分发起采购申请，确保生产需要的物料按时到位。
3.  产能计划，随着采购的推进，各个半成品加工单的物料陆续齐套，基于加工设备和工人的产能，安排加工单到合适产线，以及加工开始时间和结束时间。
4.  异常插单，订单生产计划排好了，突然有紧急单插入进来要求提前生产，怎么处理？紧急单可能挪用之前计划单的物料、设备、工人，受影响的计划单都要重新排产。

世界排名第一的免费开源Odoo ERP中，如何解决上述四个问题。

1.  第一个问题，订单分解，在Odoo ERP中，根据产品的生产BoM的层次结构，最上面一级自动生成成品装配单，中间各级生成半成品加工单。系统根据客户交期，倒算成品装配单和半成品加工单的计划开工日期。计算方法是，客户交期减去成品的制造提前期，得到装配单的计划开工日期；装配单的计划开工日期，减去半成品的制造提前期，得到半成品加工单的计划开工日期。
2.  第二个问题，物料齐套，订单分解时候，BoM层次结构中，系统计算最末级物料的需求数量，减去可用的库存数量，得到缺料数量。系统自动生成缺料数量的采购申请单或采购询价单，并自动计算采购单的计划下单日期。计划下单日期的计算方法，缺料的生产单的计划开始日期，减去该物料的采购提前期，得到计划下单日期。计算缺料，系统参考的是物料的可用库存（而不是实际库存），可用库存等于，实际库存减去被其他单子占用了的库存，加上采购在途的库存。
3.  第三个问题，产能计划，第一个问题，订单分解中，生产单的计划开工日期是简单地减去制造提前期而得，没有考虑待生产数量，也没有考虑车间产能。随着采购的推进，各个半成品加工单的物料渐次齐套。物料齐套了的生产单，计划人员（PMC岗）要安排合适的产线或设备，以及根据产线和设备的负载情况和产能，调整计划开工日期，计划完工日期。这一步，Odoo系统提供了自动排产功能。
    自动排产的基础数据设置有：1）加工中心及加工中心组。加工中心可以是一条产线，也可以是一个设备，或者一个生产小组。多个互相兼容的加工中心可以构成加工中心组，同组内的加工中心可以互相替代，系统排产时，自动查找组内有空的加工中心。2）成品/半成品的BoM表上，配置该产品适用的加工中心（产线或设备），以及产能（每小时能生产的数量）。3）车间工作时间表，如几点上班，几点下班，周几休息。如此，系统计算生产单计划完工时间时候，会用工作时间表的时间，而不是用一天24小时来计算。
    自动排产时候，系统自动安排生产单到最早有空的加工中心，自动调整生产单的计划开工时间，自动计算生产单的计划完工时间。
4.  第四个问题，异常插单，如果已经排好了生产计划，突然要在前面插入某个紧急生产单，插单显然会影响后续的排单。Odoo中处理插单的方法是，1）将插单的优先级调为高；2）释放可能受影响的后续排单，释放有两个含义，其一是释放占用的物料，其二是释放占用的加工中心。3）插单及释放的单据一键重新排产。重新排产的处理中，Odoo系统自动为插单（高优先级单）优先占用物料，优先占用设备（加工中心）。
