# 非标项目型制造的生产成本核算

非标项目型制造的生产成本核算
之前讲了项目型制造的研发设计成本的核算原理，以及在世界排名第一的Odoo ERP/MES系统中的操作方法。设计完成后，开始生产制造了，本篇讲生产制造的成本核算。
生产制造的过程中，需要领料，需要给车间工人和管理人员发工资，车间机器设备有折旧费，有电费，有厂房租金等费用。此外，还有一部分零件或工序外协加工，会产生外协费用。
在会计上，这些成本通常归纳成料、工、费，三大类。生产成本核算方法，会计上，有月末一次加权平均，移动加权平均，先进先出，计划法，个别计价法等五种方法。
实务上，生产制造型企业，一般用前三种核算方法，即月末一次加权平均，移动加权平均，先进先出 。在Odoo ERP/MES软件中，借助免费开源Odoo软件庞大的应用市场插件库，以及Odoo软件金牌服务商开源智造自研的功能插件，上述五种方法在Odoo中都可以支持。
下面以移动加权平均成本核算方法为例，介绍非标项目型制造的生产成本核算在Odoo中如何操作。

先说料的成本核算。
1. 采购料，每次采购入库时候，系统以当次采购价格和数量，库存价格和数量，以移动加权法，计算出物料新的成本价格
2. 自产料（半成品和成品），生产入库时候，系统自动加总该生产工单上的原料成本，工费成本，计算入库单价。再以该单价，和采购料相同的计算方法，计算物料新的成本价格。
3. 外协料，外协入库时候，系统自动加总外协加工单上的原料成本，以及外协费用（取自外协采购单上的外协单价），计算入库单价。再计算新的成本价格。

再说工费的成本核算。
1. 工作中心上设定小时成本。如CNC下料环节，CNC下料机是一个工作中心，测算一下该工作中心每工作一个小时的成本费用。此成本费用包含设备折旧费分摊、电费、操作工人工资、车间管理人员工资分摊、车间房租分摊等各种费用。
2. 加工工序上设定标准工时（参考用）
3. 工人实际加工完成，加工图纸上扫码报工时候，填写实际加工工时。参考之前讲解工人扫码报工的文章。
4. 实际工时，乘以工作中心上设定的小时成本，得到实际加工工费。
5. 生产工单报工关单时候，系统计算工单上的原料成本、工费成本，除以工单上入库数量，得到该成品/半成品的成本单价。

最后再讲一下订单/项目的成本核算。
1. 如之前研发设计成本核算中说的，为每个订单设立一个项目号，通常以订单号或合同号直接作为项目号。
2. 生产工单上带上项目号。生产工单确认，系统自动产生生产领料单，此生产领料单也会自动带上项目号。系统自动产生的子生产工单（零部件生产工单）也会自动带上项目号。
3. 生产工单报工关单时候，系统自动产生原料消耗的分析会计分录，以及工费消耗的分析会计分录。分析会计分录上有项目号、数量、金额、料号等信息。
4. 如此，按项目号汇总，可以得到项目的研发设计费用（参考前文，也是带项目号的分析分录）、物料消耗费用、制造费用等明细成本数据。
