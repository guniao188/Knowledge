# ERP中的审批/OA问题

> 开源智造论坛 · 市场库 | 作者:肖相扶 | 2022-12-15

**引言**

1.  ERP和OA有什么区别？

2.  ERP软件中的单据审批流程如何解决？

3.  我们应该购上ERP软件，还是上OA软件，还是两个都要？

**ERP和BPM**

OA，办公自动化软件属于BPM范畴，BPM是业务流程管理系统，侧重过程管理。ERP是企业资源计划，侧重结果管理。

行政类单位，事业类单位，类事业单位，往往程序规范比结果更重要，这种单位，更适合过程管理软件，即BPM或者OA软件。

企业单位，更强调效率和数据共享，这种单位，更适合结果管理软件，即ERP。举个例子，产品库存，企业的采购、销售、生产、财务等各个部门都要随时查看。如果库存不能共享，势必极大增加部门间沟通时间和成本。又如采购订单，仓库部门需要管理入库，财务部门需要管理应付，生产部门需要知道物料进度，这些部门都要共享采购订单。

不过，企业中也有审批的需求。举个例子，企业的请购流程规定：

需求部门提交采购申请 => 需求部门老大审批 => 采购部门老大审批 => 如果金额超过10万还要总经理审批 => 采购业务员执行采购

请购的结果是形成采购订单，但采购订单的形成过程，也希望用系统管理起来。

如果是BPM系统，这个需求比较容易，只要在BPM中新增一个请购流程，设置好各个流程节点，请购流程就可以运作起来。

但在ERP中，实现这个需求比较麻烦，需要通过二次开发，新增一个请购功能模块。常见ERP，如SAP、用友、金蝶等，审批类的需求，都要通过二次开发解决，不像BPM那样，可以配置解决。

像笔者所在的企业，世界500强的医药类企业。我们的SAP系统中，新增一个物料 ，需要需求部门（供应链或销售）申请 => 需求部门主管审批 => 财务审批 => QA审批， 审批过后，需求部门再录入系统。这个流程，我们完全是线下操作，很Low，需求部门Excel填写好物料资料，打印，送交相关部门主管签字。

**Odoo ERP实现药监局GSP审批案例**

去年年底，接到QA部门需求，我们的经营许可证快到期了，要换证。换证要过药监局的GSP审核，新的GSP标准，对IT系统有要求，例如产品注册证、证件号码、到期日期等信息，不允许直接在ERP系统中录入。需要通过“首营产品”的流程进行维护，即需要QA部门审批以后，自动填写（不允许人工直接填写或修改）。产品的新增和变更、供应商的新增和变更、客户的新增和变更，都有此要求。

GSP的这些审批流程，要求不高，需求不算复杂，但放在SAP中，难以实现，非常不好搞。我们IT正在琢磨这个事情如何解决，后来看到我们有个客户，刚换了ERP系统。他们之前用的用友U8，换成了Odoo。Odoo是一个开源免费的ERP系统，号称世界排名第一的开源ERP软件。

这个客户，去年刚刚换证，我特意留意了一下他们ERP中如何实现的GSP的审批要求。发现他们的Odoo中，有一个很好的审批功能模块，可以直接新建审批流程，配置审批节点，审批权限。比我之前考察的专业BPM软件而言，功能弱很多，但使用简单，对付企业常规审批需求足够了。

附图 Odoo ERP中 GSP首营产品审批流程：供应链申请=>供应链复核=>运营部审核=>财务部审核=>QA审核

![[4-erp-oa-59-1414353d.png]]

进一步调查了解到，Odoo开源免费，而且有大量的第三方插件（号称几万个，世界插件数量最多的企业应用平台）。那个审批模块，就是Odoo的一个第三方插件。看到我们客户的应用案例，我们IT就想，能不能用Odoo的审批流程，审批过后，再把数据传递到SAP中。联系了一下我们客户的ERP实施方开源智造，发现开源智造用Odoo做过很多SAP外挂的案例。开源智造不错，给我提供了很多Odoo的技术资料，以及实施案例资料。

年初，我整理了基于Odoo的GSP技术方案，向Global IT的头汇报了一下。出乎我意料，Global IT他们知道Odoo，说是在本部（欧洲）用的很多。因着这个原因，加上我前期调研资料准备充足，Global很容易批准了我们的技术方案。

总部批准了，接下来是招投标过程，因为前期开源智造给了我们很多帮助，相关案例也不少。招投标过程中，我们IT基本确定了开源智造负责实施。为了确保开源智造中标，我特地和几个关键的评标人打了招呼。
