# 非标项目型制造的设计成本核算

非标项目型制造的成本核算
非标项目型制造的成本，分成制造前的研发设计成本，生产制造成本，制造后的现场安装调试成本。今天先讲一下项目中的研发设计成本如何核算。
研发设计的主要成本是研发人员，财务会计对人员成本的核算，通常是月底基于HR给出的工资表，核算工资、奖金、社保等支出，作为当月人员成本。
但对项目经理来说，他关心的是哪个工程师，在哪个项目，什么时候，干了什么工作，花了多少时间，成本费用是多少。项目经理不关心，这个成本费用是工资、奖金，还是社保。
项目经理关心的项目成本费用总额，也不等于财务经理核算的当月人员成本总额。例如，春节所在月份，人员请休假多，项目干的少，项目成本很低，但基本工资，社保的支出，和正常月份基本一样，分文不少。
由此我们知道，财务经理的核算，和项目经理的核算，是两条线，独立的两条线。在会计专业领域，财务经理的核算叫财务会计，项目经理的核算叫管理会计，或分析会计。
在用友或金蝶的ERP中，有个辅助核算科目的功能，能实现少量的管理会计功能。但辅助核算科目和财务会计绑定太死，不够独立，难以实现项目经理要求的独立于财务核算的核算要求！

在世界排名第一的免费开源ERP/MES软件Odoo系统中，同时支持财务会计和管理会计的核算功能。财务会计暂且不表，Odoo中的管理会计是如何解决项目经理的核算需求呢。
核算方法如下：
1. 为每个订单，设立一个项目号
2. 为人员岗位，设立每小时的成本工资。这个成本工资包括了人员的实际工资（工资奖金社保等）支出，也包括一定的管理成本分摊。
3. 研发人员每日或每周在Odoo系统中填写工时表，填写内容包括哪个项目/哪个任务、工作内容、工作日期、工作耗时。例如，张三一天干了两个项目，A项目5小时，B项目3小时，这种情况，Odoo中填写两条工时记录。
4. 项目经理和部门经理分别审批工时表。项目经理按项目维度审批，部门经理按部门维度审批。
5. 系统结合项目工时记录，人员岗位成本，自动生成分析会计分录。
6. 系统基于分析会计分录，自动核算项目成本，部门成本。
