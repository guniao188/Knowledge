# Odoo支持一带一路公司盖泽尔发展

> [!info] 来源
> 开源智造论坛 · 市场库 | 作者:肖相扶 | 2023-08-14
> <http://www.thinkltd.cn/forum/4/odoo-3756>

张总在埃及的公司“盖泽尔贸易公司”经营油气和建筑工程用管道，随着国家一带一路的发展，张总公司业务迅速发展，日常运营却问题越来越多。部门之间缺乏整合，订单处理不及时；各种人为错误，客户投诉增加。张总希望有一个提高流程效率，方便查看库存和订单进度，及时了解财务状况，且花钱少的系统解决方案。张总在网上搜了一段时间，最后锁定了世界排名第一的免费开源一体化业务管理系统Odoo ERP，Odoo中国金牌服务商开源智造帮助张总实施了Odoo ERP！
```python
         在使用Odoo之前， 盖泽尔一直苦于订单、库存、开票、回款各业务脱节，客户投诉各部门互相推诿，不知道问题在哪。订单执行进度没有数据，一脸茫然。随着Odoo核心模块（销售、库存、会计和采购）的实施，盖泽尔的订单问题迎刃而解！该系统实现了部门之间流程无缝集成，消灭了部门间重复录入订单的工作，人为错误减少了 95%，订单处理效率提高了60%。在Odoo系统支持下，张总可以随时掌握盖泽尔运营情况，随时获取准确的财务报表，随时解决各种问题，极大提升运营效率和客户满意度。
        采用Odoo对盖泽尔的业务产生了重大影响。首先，Odoo系统大大简化和提高了订单进度等数据查询，消除了数据重复录入。流程整合，消除了部门间的扯皮，提升了部门协作效率。缩短了订单处理时间，减少了订单处理错误，最终提高了客户满意度。与SAP等商业系统相比，Odoo开源免费，在自己搞不定或没时间研究的情况下，只需要一点咨询顾问费用，成本不到商业ERP的十分之一。盖泽尔获得了实实在在的投资回报，生产力得到提高，运营卓有成效。
        盖泽尔在一个月内上线了Odoo系统，经过一段时间磨合运行，三个月内实现了业务财务一体化，获得了准确实时的财务数据。金牌服务商开源智造指导了实施的全过程，确保了系统的快速上线。随着盖泽尔业务的蓬勃发展，Odoo将始终是推动其成长和成功的宝贵资产。
```
