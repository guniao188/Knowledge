# 门店订货实现方案

> [!info] 来源
> 开源智造论坛 · 方案库 | 作者:穆宇涵 | 2023-04-25
> <http://www.thinkltd.cn/forum/3/3703>

【业务背景】

例如快餐连锁店，门店向总仓订货，要鱼排50件，鲜奶50件，洋葱10件。每件鱼排由活鱼肉1件（斤）+ 调料包1件（斤）构成。总仓实际发货活鱼50件+调料包50件，总仓鲜奶不备货，接单后汇总各门店要货单，形成采购总单，下单采购，供应商直发到各个门店，洋葱直接由总仓发货。如本例有两个门店A和B，A要鲜奶50件，B要鲜奶30件，采购找供应商采购80件，供应商直发A店50件，B店30件。

【配置要点】

1.  系统默认的“My Company”仓库改名为“总仓”

2.  新建“A店”，编码 WA，“B店”，编码WB 两个仓库。两个仓库对应实际门店，补货方式为从“总仓”补货

![[3-3703-03f696c8.png]]

![[3-3703-666b43c3.png]]

        3.系统默认的购买路线改名为“门店采购”，新增路线“总仓采购”，“门店采购”路线中的 补货仓为总仓的规则，路线调整为“总仓采购

![[3-3703-0cf21ce0.png]]

```python
        4.新建商品：鱼排、活鱼、调料包，路线为总仓采购，并设置供应商；“鲜奶”，路线为门店采购，并设置供应商；鱼排路线为"制造"

        5.新建鱼排的BoM：1件活鱼，1件调料包，BOM类型为“套件”

        6.总仓订货规则：洋葱、活鱼、调料包设置总仓订货规则（安全库存）

        7.安装订货模块“stock_request”，模块介绍参见链接：[/forum/2/question/oca-stock-request-2876](http://www.thinkltd.cn/forum/2/question/oca-stock-request-2876)

        8.设置stock_request 模块的经理权限，stock_request模块的Setting采购，开启 stock request order功能
```
