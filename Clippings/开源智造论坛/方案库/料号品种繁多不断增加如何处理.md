# 料号品种繁多不断增加如何处理

> [!info] 来源
> 开源智造论坛 · 方案库 | 作者:肖相扶 | 2022-12-21
> <http://www.thinkltd.cn/forum/3/3611>

有些行业，产品型号特别多，每个品牌都有几十万个规格型号。如电器行业，正泰有二十多万个规格型号，德力西，施耐德，西门子等品牌也各有几十万种。每个品牌厂家，每个月都会新增几百几千个规格型号。又如文具行业也是类似。

```python
         如果是电器贸易商，同时代理多个品牌的产品，品牌厂家每个月都增加几百种新产品，其ERP系统的料号数据库（产品库）如何维护？如果是电器厂家，ERP系统的料号又该如何维护？

        对于厂家，料号管理比较严谨，料号编码遵循一定的规则，设有专人负责料号新增和维护。料号新增或修改的情况，相关部门提出申请，审批后，由专人负责在ERP中新增或修改料号。
```

贸易公司的情况，料号管理不需要厂家那么严格。料号新增和维护权限同时给到销售主管或采购主管。小一些的或初创的贸易公司，为了提高制单效率，甚至每个业务员都有料号新增修改权限。

         料号管理严格，数据质量高，有利于减少业务错漏，有助于后续数据分析汇总。但因为料号新增修改都要专人负责，走申请流程，料号新增频繁的情况下，损失了业务部门制单效率。

料号管理松散，业务部门制单效率高。但一段时间后，料号重复，料号命名不统一，料号数据不规范，增加了业务错漏概率，降低了数据分析汇总价值。

         料号库如何管理，企业要根据自己的发展阶段，发展规模，动态调整管理策略。总体来说是，发展初期，规模小，管理随意。规模越大，料号库共享价值越高，数据分析越重要，料号库管理要渐趋严格。

在Odoo中，用于料号管理的工具有：

1.  Odoo自带的数据导入、导出功能：Odoo所有表单的数据都可以通过Excel导入，或导出到Excel文件。Odoo自带导入功能中，图像的导入方法是，图像字段列填写图像的URL链接（提前将图像上传到某个公网可访问的服务器上）。
2.  不同Odoo数据库间数据同步工具（支持不同版本的Odoo数据库间数据同步）：[第三方多Odoo数据库间数据自动同步管理base_synchro](http://www.thinkltd.cn/forum/2/odoobase-synchro-2815)
3.  可编程的Excel数据导入工具：[带参数执行服务器动作/上传Excel文件服务器动作进行处理base_server_action_params](http://www.thinkltd.cn/forum/2/excelbase-server-action-params-3583)
4.  基于Odoo RPC，编写数据迁移/导入的脚本程序
