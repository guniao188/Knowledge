# 餐饮门店要货及采购直发门店解决方案

> [!info] 来源
> 开源智造论坛 · 方案库 | 作者:肖相扶 | 2022-12-15
> <http://www.thinkltd.cn/forum/3/33>

【业务背景】

餐饮连锁店，如丽华快餐，门店向总仓订货，要 牛排 100件，鲜奶 100件，土豆 100件。每件牛排由 牛肉1件（斤）+ 酱油0.5件（斤）构成。总仓实际发货牛肉100件+酱油50件，总仓鲜奶不备货，接单后汇总各门店要货单，形成采购总单，下单采购，供应商直发到各个门店，土豆直接总仓发货。如本例，假设有两个门店A和B，A要鲜奶 100件，B要鲜奶80件，采购找供应商采购180件，供应商直发A店100件，B店80件。

【配置要点】

1.  系统默认的“My Company”仓库改名为“总仓”

2.  新建“A店”，编码 WA，“B店”，编码WB 两个仓库。两个仓库对应实际门店，补货方式为从“总仓”补货

3.  系统默认的Buy路线改名为“生鲜采购”，新增路线“总仓采购”，“生鲜采购”路线中的 补货仓为总仓的Rule，路线调整为“总仓采购”

4.  新建商品“土豆”、牛肉、酱油，路线为 总仓采购，设置供应商；“牛奶”，路线为 生鲜采购，设置供应商；牛排，路线为"制造"

5.  新建牛排的BoM：1件牛肉，0.5件酱油，Type为“套件(SET)”

6.  总仓订货规则：土豆、牛肉、酱油设置总仓订货规则（安全库存）

7.  安装订货模块“stock_request”，模块介绍参见链接：[/forum/2/question/oca-stock-request-2876](http://www.thinkltd.cn/forum/2/question/oca-stock-request-2876)

8.  设置stock_request 模块的经理权限，stock_request模块的Setting采购，开启 stock request order功能

【运行效果】

1.  stock_request模块，创建 A店及B店的 stock request order，订货明细包含土豆、牛排及鲜奶

2.  确认stock request order，系统自动创建 A店配送单（Picking）：总仓 --> 在途 --> A店，商品明细为 土豆、牛肉、酱油。以及B店配送单。系统也会自动创建A店及B店的鲜奶采购单。
