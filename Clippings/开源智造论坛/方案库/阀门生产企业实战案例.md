# 阀门生产企业实战案例

> [!info] 来源
> 开源智造论坛 · 方案库 | 作者:肖相扶 | 2023-07-11
> <http://www.thinkltd.cn/forum/3/16>

【业务背景】

1.  阀门生产企业多数是 小批量、定制化生产。客户订单的阀门有很多配置参数，不同配置参数的阀门，其BoM表及工艺路线都不一样。

2.  销售上，需要参数配置功能，方便业务员按客人要求选配阀门参数

3.  生产上，需要自动生成BoM，方便物料计算，及车间生产管理

4.

【实现要点】

1.  安装模块mrp_manual_production，该模块允许生产单MO上手工修改原料再确认。模块功能及使用参考：[/forum/2/question/momrp-manual-production-3106](http://www.thinkltd.cn/forum/2/question/momrp-manual-production-3106)

2.  通过Python脚本程序，将Excel的阀门参数文件，导入系统，形成带选配属性的 产品模板、及BoM模板

3.  编写一个 Server Action，方便查找阀门关联的毛坯部件（手工创建半成品）。Server Action参考：[/forum/1/question/339](http://www.thinkltd.cn/forum/1/question/339)

4.  关于产品属性的注意事项：一个属性值也显示出来的解决办法参考 [/forum/1/question/265](http://www.thinkltd.cn/forum/1/question/265)

## 补充/答案 1

【运行数据导入脚本】“阀门案例数据”中有两份数据，一份测试数据 valve_data_test.txt，大概3600条数据， 一份正式数据 valve_data_production.txt，大概 28000条数据 。脚本程序 valve_data_import.py 修改成导入测试数据的话，大概要运行 10分钟。正式数据的话，大概要运行 100分钟。

脚本运行命令：python valve_data_import.py

该脚本程序自动创建 产品属性、产品、BoM 。

## 补充/答案 2

【环境配置】

1.  依次安装 销售、采购、制造、库存 模块

2.  制造模块设置中勾选 “工单”，库存模块设置中勾选 “变体和选项”

3.  安装模块 mrp_manual_production

4.  导入“阀门案例数据” 中的工作中心( valve_work.center.csv )和工艺路线( valve_routing.csv )数据

5.  修改“阀门案例数据”中的脚本程序 valve_data_import.py 。修改程序中连接 Odoo 的URL、Database、用户名和密码，以及阀门数据文件的存放路径。
