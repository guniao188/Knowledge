# 仓库业务要点

> [!info] 来源
> 开源智造论坛 · 方案库 | 作者:肖相扶 | 2023-05-29
> <http://www.thinkltd.cn/forum/3/3667>

返回目录贴  [ERP业务要点培训大纲](http://www.thinkltd.cn/forum/3/erp-3665)

【业务要点】

1.  仓库作业：入库、出库、调拨、盘点，条码操作、包裹、托盘、双单位(公斤、捆/扎/箱/卷)
2.  仓库管理：库位、货架、上架策略、下架策略、库存、批次、效期、库龄、库存计价

【练习题一】

1.  库龄报表：请说明Odoo中如何配置实现库龄报表  -- 熊章乾
2.  请说明Odoo中，stock.move, stock.move.line, stock.quant,  stock.valuation.layer, stock.quant.package, stock.picking 之间的关系。 -- 刘祥海
3.  请说明Odoo中库存计价的计算原理，分标准价格、平均价格（移动加权平均）、FIFO（先进先出）三种计价方法分别说明。-- 沈芝玮   [库存计算原理-三种计价方法](http://www.thinkltd.cn/forum/1/3725)
4.  不锈钢贸易中，财务上按公斤计价，仓库管理上通常按捆包号进行管理，一个捆包号可能是一卷（不锈钢卷），或者一扎(不锈钢管)。每一捆有一个唯一的捆包号，原始捆包号通常是出厂时候厂家带的，在流通过程中，捆包号可能会分包（一个捆包号分割成多个小捆包），分包后的捆包号命名规则是原捆包号后面加 _1, _2 字样 。不锈钢还有炉号，不同炉号的不锈钢，其成分性能有微小差异。-- 高彩霞
5.  1.  财务上，库存数量、库存计价按公斤计算，仓库管理上，按捆包号（卷）管理更方便。在Odoo中如何处理，可以同时满足财务和仓库的管理要求
    2.  不锈钢采购时候，采购下单可能要50吨不锈钢，实际到货时候可能是5个不锈钢卷，实际重量51.3吨。一个钢卷正常重量是10吨上下，每一个钢卷都不会是标准的十吨，范围通常在9.5吨 - 10.5吨之间。采购入库时候，通常按实际到货数量入库，以及结算。这个业务在Odoo中如何处理
    3.  不锈钢销售时候，客人可能要10吨不锈钢，但要求切成三个窄卷交货。实际出货一卷9.8吨，外协加工切成三个窄卷，交付给客户。这个业务在Odoo中如何处理

【入库】

1.  入库流程：收货 --> 质检/点数  --> 打标/贴标  --> 改包 --> 上架
2.  上架策略：同品，库位类型，重量，体积
3.  条码操作：扫码上架
4.  自动设备（AGV、立体仓等）：系统接口

【练习题二】

1.  请在Odoo中配置实现入库流程  收货 --> 质检/点数  --> 打标/贴标  --> 改包 --> 上架  -- 张鹏飞
2.  请调查说明，Odoo可以和AGV怎么配合操作，提高仓库入库作业效率  -- 赵晨

【出库】

1.  出库流程：拣货 --> 验货  --> 打包/面单 --> 出库
2.  拣货策略：下架策略（先进先出、先到期先出、指定批次），波次，最短路径，摘果/播种/投篮
3.  条码操作：扫码验货，扫码出库/装车
4.  自动设备（AGV、立体仓等）：系统接口

【练习题三】

1.  整包裹锁货方案：例如，冷冻牛肉批发，冷冻牛肉每箱10公斤左右 ，原则上不允许拆箱发货。销售订单要货100公斤，仓库拣货10箱，10箱实际重量105公斤。Odoo现有功能，碰到此情况，默认系统会自动拆解包裹，从某箱中取5公斤凑满100公斤发货。希望实现功能：整箱锁货，此需求二开应该修改哪个文件哪段代码。此场景的另外一个例子是不锈钢钢卷销售。 -- 刘志鹏
2.  Odoo出库扫码验货的操作中，如果所扫商品不在出库单上，系统直接增加此商品，或者扫码商品商量超出了出库单上的数量，系统也不报错，不提醒。实际作业场景中，此种情况希望有语音提示报错。请调查Odoo 16的条码模块中，二开实现语音提示报错，关键修改点有哪些。 -- 刘志鹏
3.  电商发货场景中，一种高效的拣货、验货、打包操作流程如下。请设计一个二开方案，在Odoo中实现此作业流程。 -- 施叶寒
4.  1.  按一定策略划分拣货波次，如一个波次20单，划分波次的同时，自动为波次中每个订单绑定一个验货货架号；
```python
    2.  拣货人员按波次批量拣货；
    3.  拣货人员按波次拣完货，送到验货岗位，验货岗位从拣货篮中抓取商品，扫码，系统声音和文字提醒验货员，该商品应该放到验货货架的几号货位；
    4.  如果某个验货货架齐货了（对应订单要求的商品和数量齐货了），系统自动声音文字提醒验货员 ，并自动打印快递面单，验货员将该货架商品拿出，连同快递面单一起，放至打包台；
    5.  打包人员打包，贴快递面单。
```

【调拨】

1.  一步调拨：从源库位直接转移到目标库位
2.  两步调拨：调出库调出到在途库，调入库从在途库调入
3.  货架整理：扫码从一个货架将货物转移到另一个货架

【练习题四】

1.  请指出Odoo中两步调拨的问题，并设计一个方便的两步调拨操作方案。参考  [二开模块库间调拨stock_inter_transfer介绍](http://www.thinkltd.cn/forum/2/stock-inter-transfer-2476)  -- 穆宇涵
2.  货架整理：请说明Odoo中扫码整理货架的详细操作步骤  -- 熊章乾
