## 补充/答案 1

【准备空数据库】

1.  安装Odoo 12.0企业版，新建空白数据库（国家选择中国、语言选择英语、不加载演示数据）

2.  依次安装 Manufacture、Purchase、Sale几个应用，及补充模块 stock_mts_dateplan

3.  销售模块中开启价格表，库存模块中开启多仓库及路线，生产模块中开启 工单（Work Order），发票模块中开启 多币种

【基础配置】

1.  产品价格小数位数设置为5位

2.  销售价格表币种修改为美元

3.  新增客户“RcCarMax.com”，使用美元价格表

4.  新增产品分类 All / Internal , 成本计算方法：先进先出(FIFO)

5.

6.  产品“03010022 X9DP-2-EVA+纸箱”的销售价格设置为 148 （产品数据导入后再回过来修改）

7.  系统自带的“My Company”仓库改名为“成品仓(WH)”，再新建 电子仓(DZ) 和 机械仓(JX) 两个仓库

8.  系统自带的 Buy 路线改名为 采购(WH)，再新增两个采购路线 采购(DZ)、采购(JX) 。 采购(DZ): 供应商 -> 电子仓、采购(JX): 供应商 -> 机械仓、采购(WH): 供应商 -> 成品仓

9.  系统自带的路线 Manufacture改名为 制造(WH)，再新建路线 制造(DZ)、制造(JX) 。制造(DZ)： 含三条规则

```python
    电子仓 -> 生产 -> 电子仓

    电子仓 -> 生产 -> 机械仓

    电子仓 -> 生产 -> 成品仓

    制造(JX)：含三条规则

    机械仓 -> 生产 -> 机械仓

    机械仓 -> 生产 -> 电子仓

    机械仓 -> 生产 -> 成品仓

    制造(WH)：成品仓 -> 生产 -> 成品仓
```

10.

11. 新增外协的仓库作业类型（及对应的Sequence序号）

12. 新增 外协 路线。外协：含两条规则

```python
    机械仓 -> 生产 -> 机械仓

    成品仓 -> 生产 -> 成品仓
```

【数据导入】

新增模型 product.supplierinfo 的菜单 Supplier Info （完整路径 Inventory/Master Data/Supplier Info），模型 mrp.bom.line 的菜单 Manufacturing/Master Data/BoM Line

依次导入数据文件：res.partner 、product.template、product.supplierinfo、mrp.workcenter、mrp.routing、quality.point、product.bom、product.bom.line

导入quality.point数据时候，注意先将 仓库作业类型(Picking Type ) “电子仓: Manufacturing”  name 修改成 “电子仓: ManufacturingDZ”

导入再订货规则（安全库存）文件 stock.warehouse.orderpoint  。此文件导入之前需要替换 电子库位 和 机械库位 的外部ID。替换方法为，先导出系统库位，获得其外部ID，再批量替换。替换后再导入系统。

【生产练习】

1.  销售订单SO，注意美元价格

2.

3.  查看产品“03010022 X9DP-2-EVA+纸箱” 的BoM表

4.

5.  生产订单MO，下一个最终产品 “03010022 X9DP-2-EVA+纸箱” 的MO单

6.

7.  运行MRP（多次运行），系统按BoM表逐级展开子生产单，并按生产提前期倒排各个子生产单的计划生产日期

8.

9.

10. 查看系统自动生成的采购单（草稿）

11.

12. 计划MO单，系统自动创建工单（Work Order），查看基于工作中心的工单计划

13.

14.

15.
