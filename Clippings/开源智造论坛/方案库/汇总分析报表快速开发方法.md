参考开源方案集第7章 存货核算：

### 1.1.1          库存价值记录（库存变动明细）

存货价值记录于“存货变动明细Stock Move”上，该表有总值、余值、余数和库存价值相关字段，如下图：

l  完成数量：存货变动数量，也即入库或出库的实际数量。

l  单价：存货变动的成本价格，不同成本计算方法，其取值方法不同。

1.      标准价法：采购入库，其值取自产品上的成本价格。出库，其值取自产品上的成本价格。

2.      移动平均法：采购入库，其值取自采购明细上的去税价格。出库，其值取自产品上的成本价格。

3.      先进先出法：采购入库，其值取自采购明细上的去税价格。出库，系统按先进先出法取得批次成本价格（注意不是price_unit，批次成本价格 = 批次余值 / 批次余数），如果没有负数出库，单价 = FIFO取得的总价值 / 总数量，如果有负数出库，单价 = FIFO取得的最后一个批次的批次成本价格。

4.      全月平均法：采购入库，其值取自产品上的成本价格，但该月全月平均计算后，其值被修改为该月的全月平均价格。出库，其值取自产品上的成本价格，但该月全月平均计算后，其值被修改为该月的全月平均价格。

l  总值：存货变动总价值，入库情况为正数，出库情况为负数。不同成本计算方法，其取值方法不同。

1.      标准价法：采购入库，其值取自产品上的成本价格 * 入库数量（完成数量）。出库，其值取自产品上的成本价格 * 入库数量（完成数量）。

2.      移动平均法：采购入库，其值取自采购明细上的去税价格 * 入库数量。出库，其值取自产品上的成本价格 * 入库数量。

3.      先进先出法：采购入库，其值取自采购明细上的去税价格 * 入库数量。出库，系统按先进先出法取得批次成本价格（注意不是price_unit，批次成本价格 = 批次余值 / 批次余数），乘以批次锁货数量，得到批次锁货价值。如果没有负数出库，总值 = 批次锁货价值之和，如果有负数出库，总值 = 批次锁货价值之和 + 负数数量 * 最后一个批次成本价格。

4.      全月平均法：采购入库，其值取自产品上的成本价格 * 入库数量（完成数量），但该月全月平均计算后，其值被重算（新价格 * 入库数量）。出库，其值取自产品上的成本价格 * 入库数量（完成数量），但该月全月平均计算后，其值被重算（新价格 * 入库数量）。

l  余值：入库的情况，其初始值等于总值。出库的情况，如果没有负数出库，其值为0，如果有负数出库，其值为负数部分的价值（负数，其值 = 负数数量 * 最后一个批次成本价格）。

l  余数：入库的情况，其初始值等于完成数量。出库的情况，如果没有负数出库，其值为0，如果有负数出库，其值为负数出库的数量（负数）。

l  负数冲平：负数出库的Stock Move（强制出库），当有入库Stock Move时候，系统用入库Stock Move的余值、余数冲销负数Stock Move的余值、余数。

select SM.location_dest_id as x_loc_id, SM.product_id as x_product_id, SM.name as x_name, SM.origin as x_origin, SM.product_uom_qty as x_qty, case when SM.price_unit is null then 0.0 else SM.price_unit end as x_price_unit, case when SM.value is null then 0.0 else SM.value end as x_value, SM.date as x_date, LOC.company_id as x_company_id
