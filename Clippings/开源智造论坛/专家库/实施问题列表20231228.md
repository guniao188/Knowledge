【 高彩霞，2023年12月27日提出 】

1.  仓库的有效期的设置，目前系统中是设置到期日期，目前系统是根据入库日期作为生产日期来计算到期日期的，但是实际的业务场景应该是根据厂家的生产日期来算到期日期
2.  1.  【肖】解决办法一：在Odoo17中测试结果是，入库单上，系统会根据入库日期（当天）加上产品上设定的有效天数，算出默认的到期日期，但此到期日期是可以手工修改成你需要的日期，例如自己以生产日期 + 产品上设定的到期天数，计算一个日期，而后自己修改此到期日期。 

![[5-20231228-3844-7cd9f125.png]]

    2.  解决办法二：做一个带参数服务器动作，作业明细行上增加一个“计算到期日期”的按钮，点击按钮，调用带参数服务器动作，用户输入生产日期，系统计算到期日期，修改明细行上的到期日期字段。参考  [服务器动作增加用户参数输入弹窗base_server_action_with_params](http://www.thinkltd.cn/forum/2/base-server-action-with-params-3758)
    3.  解决办法三：作业明细行上增加一个字段“生产日期”，该字段修改时候，触发自动动作，计算到日日期，修改到期日期字段值。
3.  POS零售怎么实现实现相同的产品买一送一的规则，目前的规则只能实现到设定固定的赠送产品进行赠送
4.  1.  【肖】Odoo17促销的演示数据里面，有Buy X Get Y（买X送Y）的促销规则，该规则上X和Y可以相同，即可以配置成“买1个X送1个X”，或者“买2个X送1个X”

【葛忠彪，2023年12月27日提出】

1.  如果入库的时候单价错了，而这个产品是移动加权平均的，也用在了其他MO上，有没有标准的修复后续库存计价数据的步骤，手工自动都行
2.  1.  【肖】如果没有开启自动会计凭证功能，只是纠正产品上的当前成本价格字段，问题比较简单。可以根据该产品的stock.valuation.layer记录重算当前成本价格。如示例截图，该图中可以看出该产品一开始盘盈了数量5个，成本单价10元；而后出库了3个，成本单价10元；又入库了10个，入库单价12元。基于此记录，根据移动平均计价的计算公式，完全可以重算当前正确的成本价格。量少的情况，可以建议客户自己导出库存计价记录（SVL），在Excel中自己算，算好后修改系统中产品的成本价格字段。量多的话，可以编写一个服务器动作，自动计算当前价格。

![[5-20231228-3844-369ec022.png]]

    2.  如果是开启了自动库存会计凭证功能，问题比较复杂。计算途中，每一次入库后计算得出的成本价格，到下一次入库，期间的出库、入库对应的会计凭证都要修改。此种情况，建议系统可以辅助计算出任何时点的成本价格，但如何纠正库存计价的会计凭证，需要和客户单独讨论纠正方案。建议是，历史上错误的凭证不去修改，而是直接做一笔该产品的总调整分录，纠正该产品的当前计价。
3.  选择联系人，点击动作，发送邮件，系统上不会出现信封的图标，用户不知道发送成功了没有

![[5-20231228-3844-9e1e7d11.png]]

4.  1.  【肖】系统发送邮件有两种模式：
```python
    2.  一种是，先产生一条Odoo的Message，如果用户偏好中配置了“同时以邮件形式发送Message”，且该类型的Message开启了邮件通知。产生Odoo Message后，Odoo自动以邮件将该Message通知给用户。此种情况，该Message会显示信封标识，表示该Message邮件通知是否成功。
    3.  另一种是，系统直接发送邮件（而不是Message再通知邮件），此种情况，邮件发送成功与否，在菜单“Technical -> Email -> Emails”中查看。
    4.  本例情况，系统背后处理逻辑是，先发送邮件出去，再在该联系人下方显示一条备注类型Message（不自动邮件通知的Message），因而没有发送成功与否的信封标识。如果要显示信封，可以将备注类型Message改成自动邮件通知，参看截图。但如此，联系人将收到两个一样的邮件（一个是直接发送的，一个是备注型Message自动邮件通知的）。

![[5-20231228-3844-a6d67c02.png]]
```
